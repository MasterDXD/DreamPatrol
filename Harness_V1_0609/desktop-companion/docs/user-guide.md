# 驭·桌面伙伴 — 用户手册

## 1. 简介

**驭·桌面伙伴**是 Harness Engineering 多Agent框架的桌面可视化伴侣应用。它以一个始终置顶的透明窗口形式驻留在你的桌面上，实时反映框架的运行状态，并提供直观的交互方式来监控和操控多Agent协作流程。

桌面伙伴与 Harness 框架的关系：

- **实时连接**：通过轮询 Harness 后端 API（默认 `http://localhost:3210`），实时获取框架健康状态、Agent 活跃情况和技能加载信息
- **权限审批**：当 AI Agent 请求敏感操作权限时，桌面伙伴弹出审批卡片，由用户决定批准或拒绝
- **命令发送**：通过面板中的快捷命令按钮，直接向框架发送斜杠命令（如 `/plan`、`/build`、`/deploy`）
- **状态可视化**：27 种 AI 工作状态以不同的动画和表情直观呈现，让你一眼掌握框架在做什么

即使未连接 Harness 后端，桌面伙伴也能以演示模式独立运行，展示所有交互功能。

## 2. 安装与启动

### 系统要求

- **Node.js** 18 或更高版本
- **操作系统**：Windows / macOS / Linux
- **推荐**：同时运行 Harness 后端（`node harness-cli.js dashboard`）以获得完整体验

### 安装步骤

```bash
cd desktop-companion
npm install
```

### 启动

```bash
npm start
```

启动后桌面伙伴将出现在屏幕右下角，以经典机器人形象展示。

### 开发模式

```bash
npm run dev
```

### 打包构建

```bash
npm run build
```

## 3. 基本操作

### 鼠标交互

| 操作 | 方式 | 效果 |
|------|------|------|
| **摸摸** | 单击伙伴身体 | 显示皮肤专属语音台词，+2 XP；连续点击 2 次显示抚摸语音，+3 XP；连续 4 次触发东张西望动画，+6 XP |
| **打开控制台** | 双击伙伴身体 | 在默认浏览器中打开 Harness 监控仪表盘，+5 XP |
| **抱抱** | 长按 800ms 不松开 | 触发拥抱动画和语音，+8 XP |
| **移动位置** | 按住拖动 | 移动窗口到任意位置，拖动时身体倾斜跟随方向，松手时弹跳落地，+3 XP |
| **右键菜单** | 右键点击 | 弹出完整的上下文菜单 |

### 眼球追踪

伙伴的双眼会实时追踪你的鼠标位置。瞳孔偏移量与鼠标距离成正比，最大偏移 3.5px，营造"看着你"的生动感。

### 拖放文件

将文件从文件管理器拖放到伙伴身上：

- 伙伴进入接收状态（脉冲动画）
- 显示收到的文件名
- 触发兴奋动画（弹跳 + 开心表情）和粒子爆发效果（彩色粒子从伙伴中心向外扩散）
- +10 XP

### 悬停提示

鼠标悬停在关键部位会显示提示信息：

| 部位 | 提示内容 |
|------|---------|
| 头部 | 摸摸头~ 长按抱抱 |
| 核心能量灯 | 核心能量灯 · 点击切换状态 |
| 等级徽章 | 等级徽章 · 点击查看成长 |
| 状态指示灯 | 连接状态指示器 |
| HUD 状态点 | AI当前状态 |
| 品牌徽标 | 品牌标识 · 右键切换形象 |

## 8. 模式说明

### 极简模式

- 伙伴缩小为原始尺寸的 45%，降低亮度和饱和度
- XP 进度条、状态栏、语音气泡、HUD 自动隐藏
- 鼠标悬停时恢复完整显示
- 迷你模式下仍可接收轻量通知（顶部小标签）

### 免打扰模式

- 语音气泡完全隐藏
- Toast 通知仅显示错误类型

## 13. 常见问题 FAQ

### 为什么显示"未连接"？

桌面伙伴需要 Harness 后端运行才能连接。请先启动 Harness 后端：

```bash
node harness-cli.js dashboard
```

后端默认运行在 `http://localhost:3210`。伙伴每 5 秒自动检测连接状态，后端启动后会自动连接。

### 如何重置窗口位置？

如果伙伴窗口跑到屏幕外或位置不合适：

- **方法一**：右键 → 📌 回到默认位置
- **方法二**：系统托盘 → 显示伙伴

窗口将重置到屏幕右下角默认位置。

### 如何恢复默认设置？

如果需要清除所有自定义设置和成长数据：

1. 打开浏览器开发者工具（伙伴窗口内按 F12 或 Ctrl+Shift+I）
2. 在 Console 中执行：
   ```javascript
   localStorage.removeItem('companion-settings');
   localStorage.removeItem('companion-window-pos');
   ```
3. 重启桌面伙伴

这将清除：皮肤选择、心情模式、漫游状态、极简/免打扰/穿透模式、成长数据（等级、XP、成就）。

### 音效不播放？

桌面伙伴使用 Web Audio API 合成音效。由于浏览器安全策略，AudioContext 需要用户先与页面交互才能激活：

- **解决方法**：点击一下伙伴身体即可激活音频
- 首次点击后，后续所有音效将正常播放
- 如果音效仍然不播放，检查系统音量设置

### 伙伴窗口挡住了其他操作怎么办？

- **临时方案**：右键 → 🙈 隐藏伙伴，或按 Ctrl+Shift+H 隐藏
- **长期方案**：开启"点击穿透"模式（右键 → 🖱️ 点击穿透），伙伴身体以外的区域鼠标事件将穿透到下层窗口
- **节省空间**：开启"极简模式"（右键 → 📱 极简模式），伙伴缩小为迷你形态

### 伙伴一直不动了？

桌面伙伴在长时间无操作时会进入睡眠状态：

- 60 秒无操作 → 空闲，开始做小动作（清扫/杂耍/搬运）
- 30 秒后 → 浅睡
- 45 秒后 → 深睡，显示 ZZZ
- 70 秒后 → 熟睡

移动鼠标或点击即可唤醒伙伴。深度睡眠被唤醒时会播放惊醒动画。

### 如何查看成长进度和成就？

- 右键 → 📊 状态面板
- 面板中包含：等级、阶段、经验值、总互动次数、AI 状态、活跃角色、成就列表、事件日志

### 快捷命令有哪些？

状态面板底部提供 9 个快捷命令按钮：

| 按钮 | 命令 | 作用 |
|------|------|------|
| 📋 规划 | /plan | 触发头脑风暴 → 需求分析 → 架构设计 |
| 🔨 构建 | /build | 触发 TDD 驱动开发 → 模块开发 |
| 🔍 审查 | /review | 触发代码审查 → 安全审计 |
| 🧪 测试 | /test | 触发集成测试 |
| 🚀 部署 | /deploy | 触发完成前验证 → 部署上线 |
| 🐛 调试 | /debug | 触发系统化调试 → 缺陷修复 |
| ♻️ 重构 | /refactor | 触发系统化重构 |
| ⚡ 优化 | /optimize | 触发性能优化 |
| 📝 规格 | /spec | 触发需求分析 → 架构设计 |

### 为什么切换心情后嘴巴表情没变化？

这是一个已修复的问题。早期版本中，切换心情时嘴巴表情可能不会同步更新（尤其在未连接后端时）。现在无论是否连接后端，切换心情都会正确更新嘴巴表情。

### 为什么伙伴在漫游时停止漫游会有延迟？

这是一个已修复的问题。早期版本中，停止漫游时行走定时器未能立即清理，导致伙伴会继续走几步才停下。现在停止漫游时会立即清理行走定时器，伙伴会即时响应停止操作。

### 为什么切换形象后时间感知效果消失了？

这是一个已修复的问题。早期版本中，环境光环颜色变化仅在经典机器人形象下生效，切换到其他形象后时间感知效果会消失。现在所有形象都会根据时段显示不同的环境光环颜色。

### 为什么连接 API 后切换平静心情，嘴巴还是笑脸？

这是一个已修复的问题。早期版本中，API 连接成功后会强制覆盖当前心情设置，导致嘴巴表情始终显示为笑脸。现在 API 连接成功后会尊重当前心情设置，不再强制覆盖为笑脸。

### 为什么粒子效果（五彩纸屑/气泡/爆发粒子）只删除了最后一个？

这是一个已修复的问题。由于 JavaScript 闭包陷阱，之前所有粒子的定时删除回调都指向最后一个粒子元素。现在每个粒子都能正确地独立删除。

### 为什么切换形象或重新连接后，之前的事件监听器会重复触发？

这是一个已修复的问题。之前预加载脚本使用错误的 API 清理事件监听器，现在改用精确的 `removeListener` 方法，确保每次只保留一个监听器。

### 为什么杂耍球动画结束后球体还残留在屏幕上？

这是一个已修复的问题。杂耍球现在会在 3 秒后自动移除，不再无限累积在特效层中。

### 桌面伙伴是否安全？会不会有脚本注入风险？

桌面伙伴已采取多层安全措施防止脚本注入：

- **CSP 安全策略**：通过 Content-Security-Policy 限制页面只能加载同源脚本，禁止内联脚本和 `eval()` 执行
- **API 端点校验**：所有 API 代理请求必须以 `/api/` 开头，防止路径遍历攻击
- **内容安全渲染**：所有动态内容（事件日志、Toast 通知等）使用 `textContent` 而非 `innerHTML` 渲染，即使文本中包含 HTML 标签也不会被解析执行，从根源上杜绝 XSS 攻击
- **数据验证**：从 localStorage 恢复的成长数据（等级、经验值、成就等）均经过严格的类型和范围校验，即使存储数据被篡改或损坏也不会导致应用崩溃
- **上下文隔离**：渲染进程无法直接访问 Node.js API，所有通信通过安全的 `contextBridge` 桥接

### 优化循环状态是如何触发的？

桌面伙伴会随健康检查一起轮询优化循环状态（每5秒）。当 Harness 后端的优化循环处于运行状态时，伙伴自动切换为"优化中"状态；当优化收敛时，伙伴切换为"已收敛"状态并播放庆祝动画。这些状态也可以通过右键菜单手动触发。

## SDD 规格驱动开发

桌面伙伴集成了规格驱动开发（SDD, Spec Driven Development）的4大核心实践，按进化阶段排列：

| 实践 | 图标 | 核心理念 | 进化阶段 | 上下文成本 | 触发场景 | 对应Skill |
|------|------|---------|---------|-----------|---------|----------|
| 规格文档 | 📋 | 确保需求理解一致，先写规格再写代码 | 2 | ★★★★ | 每次给AI提需求都要重复解释时编写 | requirement-analysis |
| 同步机制 | 🔄 | 先改文档再写代码，保障文档与事实一致 | 3 | ★★★ | 直接改代码忘记更新文档时建立 | documentation |
| 反问机制 | ❓ | 强制AI不懂就问，拦截模糊需求 | 4 | ★★ | 功能复杂容易漏细节时启用 | brainstorming |
| 计划文档 | 📝 | 多文件修改先出计划，人类审核后再执行 | 5 | ★★★ | 修改涉及多文件时使用 | architecture-design |

**SDD 进化路径**：
1. **裸跑时代**（阶段1）：不写文档，仅靠接口定义让AI实现
2. **规格文档**（阶段2）：减少重复解释，确保AI与人类对需求的理解一致
3. **同步机制**（阶段3）：建立"先改文档，再写代码"的约定，防止文档与代码脱节
4. **反问机制**（阶段4）：强制AI"不懂就问"，拦截模糊需求，降低细节遗漏
5. **计划文档**（阶段5）：多文件修改时先出计划文档，人类审核后再执行

**触发方式**：
- 右键菜单 → 📋 SDD实践 → 选择对应实践
- 面板 → 📋 SDD实践 → 点击对应卡片
- 激活时获得5XP经验值奖励

**核心结论**：文档不是形式，而是保障需求理解一致、拦截细节遗漏、提升开发效率的关键。通过"规格文档+同步机制+反问机制+计划文档"的组合，可最大化发挥SDD的价值。

### 四品级分层

| 品级 | 图标 | 置信度范围 | 含义 |
|------|------|-----------|------|
| RAW | 💎 | [0, 0.5) | 原始思想，未经验证，通常被过滤 |
| CUT | 💎 | [0.5, 0.75) | 初步提炼，已通过置信度过滤 |
| POLISHED | ✨ | [0.75, 0.9) | 精炼思想，高置信度，信息密度高 |
| DIAMOND | 💎 | [0.9, 1.0] | 钻石级思想，最高品质，可追溯原始数据 |

### 四步操作

| 操作 | 图标 | 说明 | 对应品级 |
|------|------|------|---------|
| 检索思想 | 💎 | 从记忆中调取相关思想钻石 | CUT |
| 提炼思想 | ✨ | 提取核心逻辑并评估置信度 | POLISHED |
| 查重去冗 | 🔍 | 剔除重复信息保证信息密度 | POLISHED |
| 更新记忆 | 🧠 | 将精炼后的思想存入永久记忆 | DIAMOND |

### 触发方式

- **右键菜单**：右键点击伙伴 → 💎 思想钻石 → 选择操作
- **面板卡片**：打开面板 → 💎 思想钻石 → 点击对应卡片
- **激活效果**：伙伴切换到对应AI状态动画 + 语音提示 + 5XP经验值
- **提炼特效**：提炼思想时触发闪光效果（sparkle）
- **记忆更新特效**：更新记忆时触发纸屑庆祝（confetti）

### 双重过滤网

思想钻石系统采用双重过滤保证信息质量：

1. **置信度过滤**：置信度低于0.5的产出直接丢弃，不进入钻石库
2. **Jaccard去重**：与现有钻石相似度≥0.75时自动合并，保留更高置信度版本

### 根数据映射

高度抽象的思想钻石可追溯到底层原始数据块。每颗钻石的 `rootRefs` 数组存储了原始数据块的引用ID，确保抽象不脱离实际。

### 自主进化

交互即成长，思考即进化——每次五步循环都产生新的思想钻石或升级现有钻石品级。钻石库默认最多500颗，超出时按置信度排序淘汰最低品级。

## 14. 安全说明

桌面伙伴已启用 **CSP（Content Security Policy）安全策略**，通过限制页面可加载的资源来源来防范跨站脚本攻击（XSS）和代码注入风险：

- **脚本来源**：仅允许加载同源脚本，禁止内联脚本和 `eval()` 执行
- **样式来源**：仅允许同源样式表，禁止内联样式注入
- **连接来源**：`connect-src 'self' http://localhost:3210` — 允许与本地 Harness 后端通信
- **API 前缀校验**：`proxyAPI` 和 `postAPI` 均添加了 `/api/` 前缀校验，仅允许访问以 `/api/` 开头的端点，防止通过 POST 请求访问非 API 端点
- **URL协议校验**：`shell.openExternal` 调用前校验URL协议为 `http:` 或 `https:`，阻止 `file://`、`javascript:` 等危险协议
- **webContents安全封装**：异步操作后发送IPC消息前检查窗口是否已销毁，防止未捕获异常
- **请求体大小限制**：POST请求体超过1MB时自动拒绝，防止内存压力和后端过载
- **内容安全渲染**：所有动态内容（事件日志、Toast 通知）使用 `textContent` 而非 `innerHTML` 渲染，即使文本中包含 HTML 标签也不会被解析执行，从根源上杜绝 XSS 攻击
- **媒体来源**：`media-src 'self'` — 允许播放本地媒体资源
- **图片来源**：仅允许同源资源加载

如需调整 CSP 策略（例如集成第三方服务），请在主进程的 CSP 响应头配置中修改相应指令。

### 窗口恢复

在 macOS 上关闭窗口后，可通过以下方式恢复：

- **系统托盘**：右键托盘图标 → "显示伙伴"，或单击托盘图标
- **全局快捷键**：`Cmd/Ctrl+Shift+H` 切换窗口显示
- **注意**：设置 `skipTaskbar: true` 后 Dock 图标不显示，托盘是唯一恢复途径

### 权限与状态恢复

- **权限卡片关闭后**：关闭权限审批卡片时，伙伴会恢复到权限请求前的AI状态（如思考中、建造中等），而非重置为待机
- **优化服务中断**：当优化服务不可用时，伙伴会自动从"优化中"状态恢复为待机，不会卡死在优化状态
- **Toast通知限制**：同时最多显示5条Toast通知，超出时自动移除最早的，防止通知堆叠遮挡界面
- **被动奖励不计互动**：成就解锁、AI状态变化、连接框架等系统奖励的XP不计入互动次数，确保互动统计准确
- **免打扰模式增强**：升级动画（音效、纸屑、粒子效果）在免打扰模式下自动抑制，仅保留语音气泡和Toast通知
- **双击XP修正**：双击操作现在只计算双击奖励（5XP），不再与单击XP叠加，防止XP膨胀
- **Agent重新激活**：当所有Agent空闲后同一Agent再次激活时，会正确触发挥手动画和语音提示
- **命令长度限制**：斜杠命令最大长度为500字符，超长命令将被拒绝
- **窗口移动保护**：单次窗口移动偏移量限制为±100像素，防止窗口瞬间移出屏幕
- **请求速率限制**：API代理和命令发送限制为每秒8次，超限自动拒绝，防止异常请求洪泛
- **错误信息脱敏**：内部错误详情不再暴露给渲染进程，所有错误返回通用错误码
