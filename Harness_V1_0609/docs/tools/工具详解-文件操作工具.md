# 工具详解-文件操作工具

> 版本：2.73.4 | 文件：src/utils/fs-utils.js

---

## 模块概述

fs-utils是Harness框架的基础文件系统工具集，提供目录管理、JSON文件读写、哈希计算、Markdown文件扫描与解析等核心能力。它是所有模块进行文件操作的底层支撑，被RBACEnforcer、PermissionGuard、AuditLogger、SessionManager等核心组件广泛依赖。

该模块同时提供同步和异步两种API，适应不同场景的性能需求。所有文件操作均内置错误处理，通过debug-logger记录异常信息，确保框架在文件操作失败时的健壮性。

## 目录管理

### `ensureDirSync(dir)`

确保指定目录存在，若不存在则递归创建。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `dir` | string | 是 | 目录路径 |

**返回值**：`void`

**行为**：
- 目录已存在时静默返回
- 目录不存在时使用`{ recursive: true }`创建，自动创建所有中间目录

### `ensureDirAsync(dir)`

确保指定目录存在的异步版本。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `dir` | string | 是 | 目录路径 |

**返回值**：`Promise<void>`

**行为**：
- 先尝试`fs.promises.access`检查目录是否存在
- 不存在时使用`fs.promises.mkdir`递归创建
- access异常（目录不存在）时进入创建流程，其他异常正常传播

## JSON文件读写

### `loadJsonSync(filePath, sanitize)`

同步加载并解析JSON文件，支持自定义消毒器。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `filePath` | string | 是 | — | JSON文件路径 |
| `sanitize` | Function | 否 | debounced-persister.sanitize | 消毒函数，用于原型污染防护 |

**返回值**：`Object | Array | null`

- 文件不存在时返回`null`
- 解析失败时返回`null`（错误通过debug-logger记录）
- 解析成功时返回消毒后的JSON对象

**安全机制**：
- 默认使用`debounced-persister`模块的`sanitize`函数进行原型污染防护
- 可通过传入自定义`sanitize`函数覆盖默认行为
- 传入`null`或`undefined`以外的假值可禁用消毒

### `loadJsonAsync(filePath, sanitize)`

异步加载并解析JSON文件。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `filePath` | string | 是 | — | JSON文件路径 |
| `sanitize` | Function | 否 | debounced-persister.sanitize | 消毒函数 |

**返回值**：`Promise<Object | Array | null>`

行为与同步版本一致，使用`fs.promises`API。

### `readJsonDirSync(dirPath, options)`

同步批量读取目录中的所有JSON文件并解析。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `dirPath` | string | 是 | 目录路径 |
| `options` | Object | 否 | 配置选项 |
| `options.filter` | Function | 否 | 文件名过滤函数，默认匹配`.json`后缀 |
| `options.logLabel` | string | 否 | 日志标签，默认'fs-utils' |

**返回值**：`Array<{ filename: string, data: Object }>`

- 目录不存在时返回空数组
- 单个文件解析失败时跳过（错误通过debug-logger记录）
- 每个结果包含文件名和解析后的数据

### `readJsonDirAsync(dirPath, options)`

异步批量读取目录中的所有JSON文件并解析。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `dirPath` | string | 是 | 目录路径 |
| `options` | Object | 否 | 配置选项（同同步版本） |

**返回值**：`Promise<Array<{ filename: string, data: Object }>>`

## 哈希计算

### `sha256Hex(data)`

计算数据的SHA-256哈希值，返回十六进制字符串。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `data` | string | Buffer | 是 | 待哈希的数据 |

**返回值**：`string` — 64字符的十六进制哈希值

**用途**：被AuditLogger用于计算链式哈希，确保审计日志不可篡改。

### `sha256Buffer(data)`

计算数据的SHA-256哈希值，返回Buffer。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `data` | string | Buffer | 是 | 待哈希的数据 |

**返回值**：`Buffer` — 32字节的哈希Buffer

## Markdown文件操作

### `scanMarkdownDirSync(dirPath)`

同步扫描目录中的Markdown文件，返回文件名列表。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `dirPath` | string | 是 | 目录路径 |

**返回值**：`Array<string>` — Markdown文件名列表（仅文件名，不含路径）

- 目录不存在时返回空数组
- 仅返回以`.md`结尾的文件
- 扫描失败时返回空数组（错误通过debug-logger记录）

**用途**：被RBACEnforcer用于扫描`.harness/agents/`和`.harness/skills/`目录。

### `scanMarkdownDirAsync(dirPath)`

异步扫描目录中的Markdown文件。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `dirPath` | string | 是 | 目录路径 |

**返回值**：`Promise<Array<string>>`

### `parseMarkdownFile(filePath)`

同步解析Markdown文件，提取frontmatter元数据和正文内容。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `filePath` | string | 是 | Markdown文件路径 |

**返回值**：`Object | null`

| 字段 | 类型 | 说明 |
|------|------|------|
| `content` | string | 原始文件内容 |
| `frontmatter` | Object | 解析后的frontmatter元数据 |
| `body` | string | 去除frontmatter后的正文内容 |

- 文件读取失败时返回`null`
- frontmatter解析使用`constants.parseFrontmatter`
- body提取使用`constants.extractMarkdownBody`

### `parseMarkdownFileAsync(filePath)`

异步解析Markdown文件。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `filePath` | string | 是 | Markdown文件路径 |

**返回值**：`Promise<Object>`

返回结构与同步版本一致。注意：异步版本不捕获异常，由调用方处理。

## 使用示例

### 目录创建与JSON加载

```javascript
const { ensureDirSync, loadJsonSync } = require('./src/utils/fs-utils');

ensureDirSync('/path/to/project/.harness/sessions');

const config = loadJsonSync('/path/to/project/.harness/config.json');
if (config) {
  console.log('配置加载成功:', config.version);
}
```

### 异步批量读取JSON

```javascript
const { ensureDirAsync, readJsonDirAsync } = require('./src/utils/fs-utils');

await ensureDirAsync('/path/to/project/.harness/checkpoints');

const checkpoints = await readJsonDirAsync('/path/to/project/.harness/checkpoints', {
  filter: (f) => f.endsWith('.json'),
  logLabel: 'CheckpointManager',
});

for (const { filename, data } of checkpoints) {
  console.log(`检查点: ${filename}`, data.timestamp);
}
```

### 哈希计算

```javascript
const { sha256Hex, sha256Buffer } = require('./src/utils/fs-utils');

const hexHash = sha256Hex('some data to hash');
console.log('十六进制哈希:', hexHash);

const bufferHash = sha256Buffer('some data to hash');
console.log('Buffer哈希长度:', bufferHash.length);
```

### Markdown文件扫描与解析

```javascript
const { scanMarkdownDirSync, parseMarkdownFile } = require('./src/utils/fs-utils');

const agentFiles = scanMarkdownDirSync('/path/to/project/.harness/agents');
for (const file of agentFiles) {
  const parsed = parseMarkdownFile(`/path/to/project/.harness/agents/${file}`);
  if (parsed) {
    console.log(`Agent: ${file}, 角色: ${parsed.frontmatter.role}`);
    console.log(`可用技能: ${parsed.frontmatter.available_skills}`);
  }
}
```

### 自定义消毒器

```javascript
const { loadJsonSync } = require('./src/utils/fs-utils');

const customSanitize = (obj) => {
  if (obj && typeof obj === 'object') {
    delete obj.__proto__;
    delete obj.constructor;
    delete obj.prototype;
  }
  return obj;
};

const data = loadJsonSync('/path/to/file.json', customSanitize);
```

## 注意事项

- 所有路径应使用绝对路径，相对路径基于当前工作目录解析
- 同步方法适用于初始化阶段和CLI工具，异步方法适用于服务器运行时
- `loadJsonSync/Async`默认使用`debounced-persister.sanitize`进行原型污染防护
- `parseMarkdownFile`在文件读取失败时返回`null`，调用方需检查
- `parseMarkdownFileAsync`不捕获异常，调用方需自行try-catch
- `scanMarkdownDirSync/Async`仅返回文件名，不含子目录递归
- 哈希函数使用Node.js内置`crypto`模块，性能优于纯JavaScript实现
