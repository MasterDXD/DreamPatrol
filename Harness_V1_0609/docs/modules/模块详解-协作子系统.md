# 第一部分：架构概览

## 概述

协作子系统（Collaboration Subsystem）负责管理多Agent之间的协作模式选择、对话交互、任务链编排、结果融合、多样性评估、集成编排与开发指标采集。该子系统包含8个核心模块，协同完成从模式路由到最终输出合并的完整协作生命周期，并提供多样性评估、集成编排、贡献度追踪和效率度量能力。

协作子系统是Harness多Agent架构的核心运行时组件，支撑了"分层分责"原则下的Agent间通信与协调。它将协作模式从硬编码中解耦，通过信号匹配和特征推断自动选择最优协作策略，并提供从双Agent配对对话到多Agent链式处理、再到多源结果融合的完整工具链。集成编排器实现了Bagging/Boosting/Stacking三种集成学习模式，多样性管理器从四维评估团队异质性，贡献度追踪器量化每个Agent的参与价值，开发指标采集器融合ChatDev效率与成本度量方法论提供全生命周期指标追踪。

| PairChat | pair-chat.js | 配对对话，双Agent轮流发言、共识达成与交叉验证 |

| EnsembleOrchestrator | ensemble-orchestrator.js | 集成编排器，Bagging/Boosting/Stacking三种集成模式 |
| AgentContributionTracker | agent-contribution-tracker.js | Agent贡献度追踪器，权重/置信度/特征重要性/排名 |
