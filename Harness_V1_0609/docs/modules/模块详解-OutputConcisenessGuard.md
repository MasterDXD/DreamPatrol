# 模块详解：OutputConcisenessGuard（输出精简度守卫）

> 源码路径：`src/gate/output-conciseness-guard.js` | 版本：2.73.4

## 概述

OutputConcisenessGuard 是输出质量门禁，通过五个维度评估输出精简度：Token 数、行数、重复率、填充词率和代码注释率。计算综合精简度评分，追踪历史评分趋势，提供可操作的精简建议。

## 核心功能

### 五维度评估

| 维度 | 说明 | 默认阈值 |
|------|------|---------|
| Token 数 | 输出 Token 总量 | `2000` |
| 行数 | 输出行数 | `100` |
| 重复率 | 内容重复比例 | `0.3` |
| 填充词率 | 冗余措辞检测 | — |
| 代码注释率 | 注释/代码比例 | — |

### 评分机制
- 综合五维度加权评分
- 可配置惩罚阈值（`penaltyThreshold`）
- 历史趋势追踪（最多 50 条记录）

### 精简建议
- 基于超标维度生成具体建议
- 鼓励精简高效的输出风格

## 配置选项

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `maxTokens` | `2000` | 最大 Token 数 |
| `maxLines` | `100` | 最大行数 |
| `maxRepetitionRatio` | `0.3` | 最大重复率 |
| `penaltyThreshold` | `0.7` | 惩罚阈值 |
