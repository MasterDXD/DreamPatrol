## 1. UserModelManager — 用户模型管理器

**源文件**：[user-model-manager.js](../../src/runtime/user/user-model-manager.js)

### 职责概述

用户模型管理器负责持久化用户偏好、从交互中学习用户行为模式，并生成可注入到AI提示词中的用户画像。它通过SQLite存储实现偏好持久化，支持编码风格、沟通偏好、技术栈、时区等多维度用户建模。

### 构造函数参数

```javascript
new UserModelManager(options)
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `options.sqliteStore` | `object` | `null` | SQLite存储实例，用于偏好持久化 |

### 用户画像Schema

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | `string` | 用户名称 |
| `role` | `string` | 角色/职位 |
| `timezone` | `string` | 时区 |
| `codingPrefs` | `object` | 编码偏好 |
| `commStyle` | `string` | 沟通风格偏好 |
| `petPeeves` | `array` | 不喜欢的事物 |
| `projectContext` | `string` | 项目上下文 |
| `techStack` | `array` | 技术栈偏好 |

### 公共方法签名

| 方法 | 签名 | 返回值 | 说明 |
|------|------|--------|------|
| `attachSqliteStore` | `attachSqliteStore(store: object)` | `this` | 附加SQLite存储 |
| `setPreference` | `setPreference(key: string, value: any)` | `boolean` | 设置用户偏好 |
| `getPreference` | `getPreference(key: string)` | `any \| null` | 获取用户偏好 |
| `getAllPreferences` | `getAllPreferences()` | `object` | 获取所有偏好 |
| `removePreference` | `removePreference(key: string)` | `boolean` | 删除偏好 |
| `learnFromInteraction` | `learnFromInteraction(interaction: object)` | `boolean` | 从交互中学习用户偏好 |
| `buildInjectionPrompt` | `buildInjectionPrompt()` | `string` | 构建可注入AI提示词的用户画像文本 |
| `getSchema` | `getSchema()` | `object` | 获取用户画像Schema定义 |
| `getStats` | `getStats()` | `object` | 获取统计信息 |
| `isHealthy` | `isHealthy()` | `boolean` | 健康检查 |

**`learnFromInteraction` 交互对象字段**：

| 字段 | 类型 | 学习行为 |
|------|------|----------|
| `correction` | `string` | 追加到 `petPeeves` |
| `languageChoice` | `string` | 设置 `preferredLanguage` |
| `commStyle` | `string` | 设置 `commStyle` |
| `techStack` | `string[]` | 合并到 `techStack` |
| `codingStyle` | `object` | 设置 `codingPrefs` |
| `projectContext` | `string` | 设置 `projectContext` |
| `timezone` | `string` | 设置 `timezone` |

### 事件列表

| 事件名 | 载荷 | 触发时机 |
|--------|------|----------|
| `preference-set` | `{key, value}` | 偏好设置成功 |
| `preference-removed` | `{key}` | 偏好被删除 |
| `interaction-learned` | `{type}` | 从交互中学习完成 |
| `profile-injected` | `{keyCount}` | 用户画像注入完成 |

### 使用示例

```javascript
const UserModelManager = require('./src/runtime/user/user-model-manager');

const userManager = new UserModelManager({ sqliteStore });

userManager.setPreference('name', '张三');
userManager.setPreference('role', '全栈工程师');
userManager.setPreference('techStack', ['Node.js', 'React', 'PostgreSQL']);
userManager.setPreference('commStyle', '简洁直接');

userManager.learnFromInteraction({
  correction: '不要使用var声明变量',
  languageChoice: 'TypeScript',
  techStack: ['TypeScript', 'Next.js'],
});

const prompt = userManager.buildInjectionPrompt();
console.log(prompt);

const stats = userManager.getStats();
console.log(`Set: ${stats.preferencesSet}, Learned: ${stats.interactionsLearned}`);
```

## 2. AffinityLearner — 亲和力学习器

**源文件**：[affinity-learner.js](../../src/runtime/user/affinity-learner.js)

### 职责概述

亲和力学习器追踪Agent与任务类型之间的协作效果，通过指数移动平均学习亲和力分数，支持时间衰减（每小时自动衰减）和持久化存储。它为任务调度提供Agent推荐，帮助系统选择最适合特定任务类型的Agent。

### 构造函数参数

```javascript
new AffinityLearner(options)
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `options.learningRate` | `number` | `0.1` | 学习率（指数移动平均的α值） |
| `options.decayFactor` | `number` | `0.995` | 每小时衰减因子 |
| `options.minSamples` | `number` | `3` | 最低样本数，低于此数的亲和力置信度为 `low` |
| `options.maxRecords` | `number` | `1000` | 每个Agent-任务对的执行记录最大容量 |
| `options.sqliteStore` | `object` | `null` | SQLite存储实例 |

**静态常量**：

| 常量 | 值 | 说明 |
|------|-----|------|
| `AffinityLearner.LEARNING_RATE` | `0.1` | 默认学习率 |
| `AffinityLearner.DECAY_FACTOR` | `0.995` | 默认衰减因子 |
| `AffinityLearner.MIN_SAMPLES` | `3` | 默认最低样本数 |

### 公共方法签名

| 方法 | 签名 | 返回值 | 说明 |
|------|------|--------|------|
| `attachSqliteStore` | `attachSqliteStore(store: object)` | `this` | 附加SQLite存储并加载已有数据 |
| `recordExecution` | `recordExecution(agentId: string, taskType: string, qualityScore: number, duration?: number)` | `void` | 记录一次执行并更新亲和力 |
| `getAffinity` | `getAffinity(agentId: string, taskType: string)` | `{score, confidence, samples}` | 获取指定Agent-任务对的亲和力 |
| `getRecommendations` | `getRecommendations(taskType: string, agentIds: string[])` | `Array<{agentId, score, confidence, samples}>` | 获取Agent推荐列表（按分数降序） |
| `decay` | `decay()` | `void` | 手动触发衰减（每小时自动执行） |
| `getAgentPerformance` | `getAgentPerformance(agentId: string)` | `object<taskType, {score, samples, averageScore}>` | 获取Agent在各任务类型上的表现 |
| `getStats` | `getStats()` | `object` | 获取统计信息 |
| `isHealthy` | `isHealthy()` | `boolean` | 健康检查 |

**置信度等级**：

| 条件 | 置信度 |
|------|--------|
| `samples < 3` | `'low'` |
| `3 ≤ samples < 5` | `'low'` |
| `5 ≤ samples < 10` | `'medium'` |
| `samples ≥ 10` | `'high'` |

**亲和力更新公式**：

```
newScore = currentScore + learningRate × (qualityScore - currentScore)
```

### 事件列表

| 事件名 | 载荷 | 触发时机 |
|--------|------|----------|
| `execution-recorded` | `{agentId, taskType, qualityScore, key}` | 执行记录完成 |
| `affinities-decayed` | `{}` | 亲和力衰减完成 |
| `loaded-from-store` | `{count}` | 从存储加载数据完成 |
| `load-error` | `{error}` | 加载数据失败 |

### 使用示例

```javascript
const AffinityLearner = require('./src/runtime/user/affinity-learner');

const learner = new AffinityLearner({
  learningRate: 0.15,
  decayFactor: 0.99,
  minSamples: 5,
  sqliteStore,
});

learner.recordExecution('task-worker', 'tdd-implement', 0.9, 120000);
learner.recordExecution('task-worker', 'tdd-implement', 0.85, 90000);
learner.recordExecution('task-worker', 'tdd-implement', 0.92, 110000);
learner.recordExecution('domain-analyst', 'tdd-implement', 0.7, 180000);

const affinity = learner.getAffinity('task-worker', 'tdd-implement');
console.log(`Score: ${affinity.score.toFixed(3)}, Confidence: ${affinity.confidence}`);

const recommendations = learner.getRecommendations('tdd-implement', [
  'task-worker', 'domain-analyst', 'quality-assurance',
]);
for (const rec of recommendations) {
  console.log(`${rec.agentId}: ${rec.score.toFixed(3)} (${rec.confidence})`);
}

const performance = learner.getAgentPerformance('task-worker');
console.log('Performance:', performance);
```

## 3. StructuredIntent — 结构化意图

**源文件**：[structured-intent.js](../../src/runtime/user/structured-intent.js)

### 职责概述

结构化意图解析器将用户自然语言消息解析为结构化任务参数，支持多轮会话参数累积、完整性评估、澄清提示生成和先验信息丰富度评估。它内置8种Skill的参数Schema，支持自定义Schema注册。

### 构造函数参数

```javascript
new StructuredIntent(options)
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `options.customSchemas` | `object` | `{}` | 自定义Skill参数Schema |
| `options.maxHistory` | `number` | `200` | 解析历史最大条目数 |
| `options.completenessThreshold` | `number` | `0.6` | 完整性阈值，低于此值触发澄清 |
| `options.maxSessions` | `number` | `50` | 最大会话参数缓存数 |
| `options.maxSchemas` | `number` | `100` | 最大Schema注册数（超限时FIFO淘汰最早注册的） |

### 内置Skill Schema

| Skill ID | 必需参数 | 可选参数 |
|----------|----------|----------|
| `tdd-implement` | `target_module`, `success_criteria` | `constraints`, `test_framework` |
| `module-development` | `module_name`, `requirements` | `dependencies`, `architecture_pattern` |
| `code-review` | `target_files`, `review_focus` | `severity_threshold` |
| `architecture-design` | `system_name`, `core_requirements` | `constraints`, `existing_modules` |
| `bug-fix` | `bug_description`, `expected_behavior` | `reproduction_steps`, `affected_versions` |
| `security-audit` | `audit_scope` | `severity_focus`, `compliance_standards` |
| `deployment` | `environment`, `version` | `rollback_plan`, `health_check_url` |
| `integration-testing` | `test_scope` | `test_environments`, `critical_paths` |

**静态属性**：`StructuredIntent.INTENT_SCHEMAS` — 内置Schema定义

### 公共方法签名

| 方法 | 签名 | 返回值 | 说明 |
|------|------|--------|------|
| `parseIntent` | `parseIntent(userMessage: string, skillId?: string, options?: {sessionId?})` | `{skillId, params, completeness, missingParams, clarificationNeeded, clarificationPrompt, rawMessage, paramsAccumulated}` | 解析用户意图 |
| `getSchema` | `getSchema(skillId: string)` | `schema \| null` | 获取指定Skill的参数Schema |
| `registerSchema` | `registerSchema(skillId: string, schema: object)` | `boolean` | 注册自定义Schema（不允许覆盖内置） |
| `validateIntent` | `validateIntent(intent: object)` | `{valid, errors, warnings}` | 验证意图对象完整性 |
| `assessPriorRichness` | `assessPriorRichness(userMessage: string)` | `{score, level, signals}` | 评估用户消息的先验信息丰富度 |
| `generateQualityReport` | `generateQualityReport(userMessage: string, skillId: string, sessionId?: string)` | `{priorRichness, intent, firstMessageVibe, convergenceSpeed, suggestions}` | 生成意图质量报告 |
| `enhancePrompt` | `enhancePrompt(userMessage: string, skillId: string)` | `string` | 增强用户提示词 |
| `clearSession` | `clearSession(sessionId: string)` | `void` | 清除指定会话的参数缓存 |
| `getSessionParams` | `getSessionParams(sessionId: string, skillId: string)` | `object \| null` | 获取会话累积参数 |
| `getStats` | `getStats()` | `object` | 获取统计信息 |

**先验信息丰富度等级**：

| 分数 | 等级 | 说明 |
|------|------|------|
| `≥ 4` | `low-entropy` | 信息充分，无需补充 |
| `2 - 3.5` | `medium-entropy` | 部分信息缺失 |
| `< 2` | `high-entropy` | 信息严重不足 |

**信号检测维度**：

| 信号 | 说明 |
|------|------|
| `scenario-detail` | 场景细节（如"在XX环境中"） |
| `role-identity` | 身份定位（如"作为XX工程师"） |
| `explicit-constraint` | 显式约束（如"必须/禁止"） |
| `depth-expectation` | 深度期望（如"深入分析原理"） |
| `technical-specificity` | 技术术语（3个以上技术名词） |

### 事件列表

| 事件名 | 载荷 | 触发时机 |
|--------|------|----------|
| `intent-parsed` | `result` | 意图解析完成 |
| `schema-registered` | `{skillId}` | 自定义Schema注册成功 |

### 使用示例

```javascript
const StructuredIntent = require('./src/runtime/user/structured-intent');

const intent = new StructuredIntent({
  completenessThreshold: 0.5,
  maxHistory: 100,
});

const result = intent.parseIntent(
  '请对src/utils/目录下的文件进行代码审查，重点关注安全性',
  'code-review',
  { sessionId: 'session-001' }
);

console.log('Completeness:', result.completeness);
console.log('Params:', result.params);
if (result.clarificationNeeded) {
  console.log('Clarification:', result.clarificationPrompt);
}

const richness = intent.assessPriorRichness(
  '作为后端工程师，在Node.js项目中使用Express框架，必须遵守RESTful规范，深入分析API设计原理'
);
console.log(`Richness: ${richness.level} (score: ${richness.score})`);
console.log('Signals:', richness.signals);

const report = intent.generateQualityReport(
  '帮我实现一个用户认证模块',
  'tdd-implement'
);
console.log('Suggestions:', report.suggestions);

const enhanced = intent.enhancePrompt('帮我写测试', 'tdd-implement');
console.log('Enhanced prompt:', enhanced);

intent.clearSession('session-001');
```

```
┌──────────────────────────────────────────────────────────────┐
│                       用户子系统                               │
│                                                                │

│  │ UserModelManager │◄─── 用户偏好读写 ──── SQLite Store      │

│  │ StructuredIntent │     │ AffinityLearner  │               │
│  │  (意图解析/增强)  │     │  (亲和力学习)     │               │
│  └──────────────────┘     └────────┬─────────┘               │

│                              任务调度器/路由器                  │
└──────────────────────────────────────────────────────────────┘
```

### 协作流程

1. **用户交互** → `UserModelManager.learnFromInteraction()` 从交互中提取偏好
2. **偏好持久化** → `UserModelManager.setPreference()` 写入SQLite
3. **画像注入** → `UserModelManager.buildInjectionPrompt()` 生成提示词注入文本
4. **意图解析** → `StructuredIntent.parseIntent()` 解析用户消息为结构化参数
5. **质量评估** → `StructuredIntent.assessPriorRichness()` 评估信息丰富度
6. **提示增强** → `StructuredIntent.enhancePrompt()` 补充缺失参数提示
7. **亲和力记录** → `AffinityLearner.recordExecution()` 记录Agent执行效果
8. **Agent推荐** → `AffinityLearner.getRecommendations()` 按亲和力推荐Agent

## 补充摘要：用户管理与用户特定上下文

用户子系统（User Subsystem）由 UserModelManager、AffinityLearner 和 StructuredIntent 三个模块构成，实现从用户画像构建到个性化任务执行的完整链路。UserModelManager 管理用户多维画像（编码偏好、沟通风格、技术栈、时区等），通过 `learnFromInteraction()` 从每次交互中自动学习行为模式，并通过 `buildInjectionPrompt()` 生成可注入 AI 提示词的画像文本，实现个性化的系统行为。画像数据通过 SQLite 持久化，确保跨会话信息不丢失。

StructuredIntent 解析用户自然语言消息为结构化任务参数，支持 8 种内置 Skill 参数 Schema 和自定义 Schema 注册。通过 `assessPriorRichness()` 评估用户输入的先验信息丰富度（low-entropy/medium-entropy/high-entropy 三级），当信息不足时触发澄清提示。AffinityLearner 通过指数移动平均学习 Agent 与任务类型的匹配效果，为 MultiAgentRouter 提供基于历史表现的 Agent 推荐排序，实现"适合的人做适合的事"。三个模块协作形成完整的用户感知链路：用户画像 → 意图解析 → 任务路由。

源文件：`src/runtime/user/user-model-manager.js`、`src/runtime/user/affinity-learner.js`、`src/runtime/user/structured-intent.js`。
