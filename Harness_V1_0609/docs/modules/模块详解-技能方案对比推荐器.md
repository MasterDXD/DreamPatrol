# 模块详解-技能方案对比推荐器

> 版本：2.73.4 | 文件：src/runtime/skill/skill-comparison-recommender.js | 融合来源：find-skills方案对比推荐

---

## 概述

技能方案对比推荐器（SkillComparisonRecommender）融合了find-skills的方案对比推荐核心能力，为同一任务推荐多种可选技能组合并对比优劣。原有技能子系统缺少"方案对比"视角——SkillRouter仅返回匹配的技能列表，SkillEffectivenessOptimizer仅优化选择顺序，均无法对同一任务推荐多个可选方案并评分比较。本模块填补了这一空白，支持多维度评分、优缺点分析和方案推荐。

### 解决的问题

| 问题 | 原有方案 | 本模块方案 |
|------|---------|-----------|
| 缺少方案对比视角 | SkillRouter返回单一匹配列表，无替代方案 | recommend()返回多种替代方案并评分比较 |
| 无多维度评分 | 仅按phase+priority排序 | 四维度评分（质量/速度/可靠性/覆盖度） |
| 缺少优缺点分析 | 无结构化优缺点输出 | _generateProsCons()自动生成方案优缺点 |
| 无法量化方案差异 | 无法量化比较不同技能组合的优劣 | compareSolutions()量化对比指定方案 |

### 融合策略

| 维度 | 评估结果 | 融合方案 |
|------|---------|---------|
| 方案对比 | 核心特性，高度匹配 | 原生Node.js实现，四维度评分体系 |
| 多方案推荐 | 高度匹配 | recommend()返回主方案+替代方案 |
| 优缺点分析 | 高度匹配 | _generateProsCons()自动分析 |
| 缓存管理 | 中等匹配 | BoundedMap缓存评分结果 |

## 常量

### DEFAULT_COMPARISON_CONFIG

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| maxAlternatives | `3` | 最大替代方案数 |
| minQualityScore | `0.5` | 最低质量评分，低于此值的方案被过滤 |
| comparisonDimensions | 见下表 | 对比维度配置 |

### COMPARISON_DIMENSIONS

| 维度 | 值 | 说明 |
|------|-----|------|
| QUALITY | `'quality'` | 质量维度 |
| SPEED | `'speed'` | 速度维度 |
| RELIABILITY | `'reliability'` | 可靠性维度 |
| COVERAGE | `'coverage'` | 覆盖度维度 |

### DIMENSION_WEIGHTS

| 维度 | 权重 | 说明 |
|------|------|------|
| quality | `0.3` | 质量权重最高，确保推荐方案的质量底线 |
| speed | `0.2` | 速度权重 |
| reliability | `0.3` | 可靠性权重与质量并列最高，确保方案稳定 |
| coverage | `0.2` | 覆盖度权重 |

## 类定义

```javascript
class SkillComparisonRecommender extends EventEmitter {
  constructor(options)
  attachSkillRouter(router)
  attachQualityIndex(qualityIndex)
  attachEffectivenessOptimizer(optimizer)
  recommend(taskDescription, options)
  compareSolutions(solutions)
  _scoreQuality(solution)
  _scoreSpeed(solution)
  _scoreReliability(solution)
  _scoreCoverage(solution)
  _generateProsCons(solutions)
  getStats()
  shutdown() // via withShutdown mixin
}
```

## 构造函数

```javascript
const recommender = new SkillComparisonRecommender({
  maxAlternatives: 3,
  minQualityScore: 0.5,
  comparisonDimensions: ['quality', 'speed', 'reliability', 'coverage'],
});
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `maxAlternatives` | number | `3` | 最大替代方案数 |
| `minQualityScore` | number | `0.5` | 最低质量评分阈值 |
| `comparisonDimensions` | string[] | 四维度 | 参与对比的维度列表 |

| 属性 | 类型 | 说明 |

## 方法详解

### attachSkillRouter(router)

挂载SkillRouter。注入后推荐器可获取技能列表和路由匹配结果。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `router` | SkillRouter | SkillRouter实例 |

**返回：** `SkillComparisonRecommender` — 支持链式调用

---

### attachQualityIndex(qualityIndex)

挂载技能质量索引。注入后推荐器可获取技能质量评分数据。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `qualityIndex` | SkillQualityIndex | 技能质量索引实例 |

**返回：** `SkillComparisonRecommender` — 支持链式调用

---

### attachEffectivenessOptimizer(optimizer)

挂载技能效能优化器。注入后推荐器可获取技能效能指标用于评分。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `optimizer` | SkillEffectivenessOptimizer | 技能效能优化器实例 |

**返回：** `SkillComparisonRecommender` — 支持链式调用

---

### recommend(taskDescription, options)

推荐多种替代方案。根据任务描述，从SkillRouter匹配结果中生成主方案和多个替代方案，并对每个方案进行四维度评分。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `taskDescription` | string | 任务描述文本 |
| `options` | Object | 可选配置 |
| `options.maxAlternatives` | number | 覆盖默认最大替代方案数 |
| `options.minQualityScore` | number | 覆盖默认最低质量评分 |

**返回：**

```javascript
{
  taskDescription: string,
  primary: {
    skills: SkillDef[],
    scores: { quality, speed, reliability, coverage, overall },
    pros: string[],
    cons: string[],
  },
  alternatives: Array<{
    skills: SkillDef[],
    scores: { quality, speed, reliability, coverage, overall },
    pros: string[],
    cons: string[],
    differenceFromPrimary: { quality, speed, reliability, coverage },
  }>,
  recommendation: 'primary' | 'alternative_N',
  reason: string,
}
```

**逻辑：**
1. 通过SkillRouter.match()获取匹配技能列表
2. 构建主方案（Top-K技能组合）
3. 构建替代方案（替换部分技能或调整顺序）
4. 对每个方案执行四维度评分
5. 生成优缺点分析
6. 综合评分确定推荐方案

---

### compareSolutions(solutions)

对比指定方案。对用户提供的多个技能组合方案进行四维度评分对比。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `solutions` | Array\<{ skills: SkillDef[] }\> | 待对比的方案列表 |

**返回：**

```javascript
{
  solutions: Array<{
    skills: SkillDef[],
    scores: { quality, speed, reliability, coverage, overall },
    pros: string[],
    cons: string[],
  }>,
  comparison: {
    bestByDimension: { quality, speed, reliability, coverage },
    overallBest: number,
    tradeoffs: string[],
  },
}
```

---

### _scoreQuality(solution)

质量维度评分。评估方案中技能组合的整体质量水平。

**评分来源：**
- SkillQualityIndex的质量评分（已挂载时）
- 技能的enforcement级别
- 技能的验证状态（verified）

**返回：** `number` — 0-1之间的质量评分

---

### _scoreSpeed(solution)

速度维度评分。评估方案中技能组合的执行速度预期。

**评分来源：**
- SkillEffectivenessOptimizer的历史延迟数据（已挂载时）
- 技能的L2缓存命中状态
- 技能层级（核心层 > 领域层 > 基础设施层）

**返回：** `number` — 0-1之间的速度评分

---

### _scoreReliability(solution)

可靠性维度评分。评估方案中技能组合的稳定性和成功率预期。

**评分来源：**
- SkillQualityIndex的成功率数据（已挂载时）
- 技能的stability级别（stable > experimental > unverified）
- 金丝雀发布状态

**返回：** `number` — 0-1之间的可靠性评分

---

### _scoreCoverage(solution)

覆盖度维度评分。评估方案对任务需求的覆盖程度。

**评分来源：**
- 技能的阶段覆盖范围
- 语义分组覆盖度
- 依赖链完整性

**返回：** `number` — 0-1之间的覆盖度评分

---

### _generateProsCons(solutions)

优缺点分析。基于四维度评分结果，为每个方案自动生成结构化的优缺点描述。

**逻辑：**
1. 对每个方案，找出评分最高和最低的维度
2. 最高维度 → 生成优点描述
3. 最低维度 → 生成缺点描述
4. 与其他方案对比，突出差异化优缺点

**返回：** `Array<{ pros: string[], cons: string[] }>`

---

### getStats()

获取统计信息。

**返回：**

```javascript
{
  totalRecommendations: number,    // 总推荐次数
  totalComparisons: number,        // 总对比次数
  avgAlternativesPerRecommend: number,  // 平均替代方案数
  cacheHitRate: number,            // 评分缓存命中率
  dimensionAverages: {             // 各维度平均评分
    quality: number,
    speed: number,
    reliability: number,
    coverage: number,
  },
  skillRouterAttached: boolean,
  qualityIndexAttached: boolean,
  effectivenessOptimizerAttached: boolean,
}
```

## 四维度评分体系

### 评分维度与权重

```
overall = quality × 0.3 + speed × 0.2 + reliability × 0.3 + coverage × 0.2
```

| 维度 | 权重 | 评估重点 | 数据来源 |
|------|------|---------|---------|
| quality | 0.3 | 技能质量水平、验证状态、enforcement级别 | SkillQualityIndex |
| speed | 0.2 | 执行速度、缓存命中、技能层级 | SkillEffectivenessOptimizer |
| reliability | 0.3 | 成功率、稳定性级别、金丝雀状态 | SkillQualityIndex |
| coverage | 0.2 | 阶段覆盖、语义覆盖、依赖完整性 | SkillRouter |

### 评分流程

```
recommend() 执行流程：
  1. 前置检查
     ├── SkillRouter挂载检查
     ├── 任务描述非空检查
     └── 最低质量评分检查

  2. 技能匹配
     └── skillRouter.match({ userMessage: taskDescription })

  3. 方案构建
     ├── 主方案：Top-K技能组合
     └── 替代方案：替换/调整技能组合（最多maxAlternatives个）

  4. 四维度评分
     ├── _scoreQuality(solution)     → quality评分
     ├── _scoreSpeed(solution)       → speed评分
     ├── _scoreReliability(solution) → reliability评分
     └── _scoreCoverage(solution)    → coverage评分

  5. 优缺点分析
     └── _generateProsCons(solutions)

  6. 综合推荐
     ├── 按overall评分排序
     ├── 过滤低于minQualityScore的方案
     └── 生成推荐理由
```

## 使用示例

### 基本推荐

```javascript
const SkillComparisonRecommender = require('./src/runtime/skill/skill-comparison-recommender');

const recommender = new SkillComparisonRecommender({
  maxAlternatives: 3,
  minQualityScore: 0.5,
});

// 挂载依赖
recommender
  .attachSkillRouter(skillRouter)
  .attachQualityIndex(qualityIndex)
  .attachEffectivenessOptimizer(effectivenessOptimizer);

// 推荐方案
const result = recommender.recommend('实现用户认证模块并添加单元测试');
console.log('主方案:', result.primary.skills.map(s => s.skill_id));
console.log('主方案评分:', result.primary.scores);
console.log('替代方案数:', result.alternatives.length);

result.alternatives.forEach((alt, i) => {
  console.log(`替代方案${i + 1}:`, alt.skills.map(s => s.skill_id));
  console.log(`  评分:`, alt.scores);
  console.log(`  优点:`, alt.pros);
  console.log(`  缺点:`, alt.cons);
});
```

### 方案对比

```javascript
// 对比用户指定的两个方案
const comparison = recommender.compareSolutions([
  { skills: [tddSkill, codeReviewSkill] },
  { skills: [integrationTestSkill, securityAuditSkill] },
]);

console.log('最佳质量方案:', comparison.comparison.bestByDimension.quality);
console.log('最佳速度方案:', comparison.comparison.bestByDimension.speed);
console.log('综合最佳方案:', comparison.comparison.overallBest);
console.log('权衡分析:', comparison.comparison.tradeoffs);
```

### 自定义维度权重

```javascript
// 对安全性要求高的场景，提高可靠性权重
const recommender = new SkillComparisonRecommender({
  maxAlternatives: 2,
  minQualityScore: 0.7,
  comparisonDimensions: ['quality', 'speed', 'reliability', 'coverage'],
});

// 通过DIMENSION_WEIGHTS调整权重（在构造函数options中覆盖）
```

## 与其他模块的集成

| 模块 | 集成方式 | 说明 |
|------|---------|------|
| SkillRouter | 依赖注入 | 通过attachSkillRouter()注入，获取技能匹配结果 |
| SkillQualityIndex | 依赖注入 | 通过attachQualityIndex()注入，获取质量评分和成功率数据 |
| SkillEffectivenessOptimizer | 依赖注入 | 通过attachEffectivenessOptimizer()注入，获取效能指标和延迟数据 |
| BoundedMap | 直接使用 | 评分缓存，支持容量限制 |
| shutdown-mixin | 继承 | 使用withShutdown混入，支持优雅关闭 |

### 集成架构

```
SkillRouter.match() ──匹配结果──→ SkillComparisonRecommender
                                        │
                    SkillQualityIndex ───┤
                    (质量/成功率数据)      ├── 四维度评分
                                        │
                    SkillEffectivenessOptimizer ──┤
                    (效能/延迟数据)                 │
                                                  ▼
                                          recommend() / compareSolutions()
                                                  │
                                                  ▼
                                          结构化推荐结果
                                          (主方案 + 替代方案 + 优缺点)
```

---

## 关闭行为

`shutdown()` 执行以下清理操作：

1. 清空评分缓存（`_scoreCache`）
2. 关闭BoundedMap（`_scoreCache.shutdown()`）
3. 置空SkillRouter、SkillQualityIndex、SkillEffectivenessOptimizer引用
