# 模块详解：ErrorPreventionGuard（错误预防守卫）

> 源码路径：`src/gate/error-prevention-guard.js` | 版本：2.73.4

## 概述

ErrorPreventionGuard 是代码质量门禁的一部分，在代码变更进入主干前主动检测潜在错误。通过静态分析、模式匹配和历史错误学习，识别常见错误模式并提供预防建议。

## 核心功能

### 错误模式检测
- 空指针/未定义引用检测
- 异步未处理检测
- 资源泄漏检测

### 历史学习
- 基于历史错误记录的学习
- 错误模式匹配引擎

### 预防建议
- 自动生成修复建议
- 风险等级评估
