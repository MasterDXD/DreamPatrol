# 模块详解-上下文预算优化器

> 版本：2.73.4 | 文件：src/runtime/infrastructure/context-budget-optimizer.js | 行数：~234行

---

## 模块定位

ContextBudgetOptimizer是上下文预算优化器，基于EventEmitter扩展，是基础设施子系统的上下文成本管理组件。它实现了5层上下文成本层级模型（PROJECT_MEMORY > SKILLS > MCP > SUBAGENTS > HOOKS），根据可用上下文窗口动态分配各层加载配额，支持预算分配、回收、重分配和阈值告警，优化上下文利用率。该模块融合了Claude Code扩展功能的上下文成本分层模型，确保高优先级特性优先获得上下文资源。

## 设计理念

Claude Code扩展在加载项目记忆（CLAUDE.md）、技能包、MCP连接、子Agent和Hook时，会占用大量上下文窗口。不同特性对上下文的消耗不同，优先级也不同。ContextBudgetOptimizer通过分层预算模型，确保：

- **高优先级特性优先加载**：PROJECT_MEMORY层拥有最高优先级和最大预算配额
- **预算动态调整**：根据实际使用模式重分配预算，低利用率层可向高利用率层让渡资源
- **阈值告警**：当总体利用率达到警告或危险阈值时，自动触发事件通知
- **回收与重分配**：支持从低优先级层回收预算，重新分配给需要的层

## 类定义

```javascript
class ContextBudgetOptimizer extends EventEmitter {
  constructor(config)
  canLoad(layer, itemId, estimatedTokens)
  registerLoad(layer, itemId, tokenCount)
  unregisterLoad(layer, itemId, tokenCount)
  reclaimFromLayer(layer, targetTokens)
  reallocateBudgets(usagePattern)
  getBudgetStatus()
  getRecommendations()
  getStats()
  shutdown() // via withShutdown mixin
  isHealthy()
}
```

## 构造函数

### `constructor(config)`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `config` | object | 否 | 配置选项 |
| `config.maxContextTokens` | number | 否 | 最大上下文Token数，默认200000 |
| `config.warningThreshold` | number | 否 | 警告阈值（利用率比例），默认0.8 |
| `config.dangerThreshold` | number | 否 | 危险阈值（利用率比例），默认0.95 |
| `config.maxHistorySize` | number | 否 | 历史记录最大容量，默认200 |

初始化内部状态：
- `_layerUsage` — 基于BoundedMap的各层当前Token使用量
- `_layerBudgets` — 各层分配的Token预算
- `_layerLoaded` — 各层已加载项ID的Set集合
- `_totalUsed` — 总已使用Token数
- `_stats` — 统计信息（分配次数、拒绝次数、回收次数、各层统计）

构造时自动调用`_allocateBudgets()`按`LAYER_DEFAULT_BUDGET_RATIO`分配初始预算。

## 公开方法详解

### `canLoad(layer, itemId, estimatedTokens)`

检查指定特性是否可以在预算内加载。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `layer` | string | 是 | 特性层级，取值来自FEATURE_LAYERS |
| `itemId` | string | 是 | 特性项标识符 |
| `estimatedTokens` | number | 是 | 预估Token消耗量 |

**返回值**：`boolean` — 预算足够返回true，否则返回false

**行为细节**：
- 无效层级直接返回false
- 当前层使用量 + 预估Token > 层预算时返回false，并触发`budget-exceeded`事件
- 拒绝时更新统计信息

### `registerLoad(layer, itemId, tokenCount)`

注册已加载的特性项，扣减对应层预算。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `layer` | string | 是 | 特性层级 |
| `itemId` | string | 是 | 特性项标识符 |
| `tokenCount` | number | 是 | 实际Token消耗量 |

**返回值**：`boolean` — 注册成功返回true，预算不足返回false

**行为细节**：
- 超出预算时触发`budget-exceeded`事件
- 成功时更新使用量、已加载项集合、总使用量和统计信息
- 更新层峰值使用量
- 触发`item-loaded`事件
- 自动检查阈值

### `unregisterLoad(layer, itemId, tokenCount)`

注销已加载的特性项，释放对应层预算。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `layer` | string | 是 | 特性层级 |
| `itemId` | string | 是 | 特性项标识符 |
| `tokenCount` | number | 是 | 释放的Token数量 |

**返回值**：`boolean` — 注销成功返回true，项不存在返回false

**行为细节**：
- 项不在已加载集合中时返回false
- 使用量不低于0
- 触发`item-unloaded`事件

### `reclaimFromLayer(layer, targetTokens)`

从指定层回收预算（卸载低优先级项）。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `layer` | string | 是 | 目标层级 |
| `targetTokens` | number | 是 | 目标回收Token数 |

**返回值**：`number` — 实际回收的Token数

**行为细节**：
- 回收量不超过当前层使用量
- 清空该层所有已加载项
- 触发`budget-reclaimed`事件
- 更新统计信息

### `reallocateBudgets(usagePattern)`

根据实际使用模式重分配各层预算。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `usagePattern` | object | 是 | 使用模式，格式为`{ layer: desiredRatio }` |

**返回值**：无

**行为细节**：
- 自动归一化比例（总和为1）
- 比例总和 ≤ 0 时不执行
- 触发`budgets-reallocated`事件

### `getBudgetStatus()`

获取所有层的预算状态。

**返回值**：

```javascript
{
  totalUsed: number,       // 总已使用Token
  totalBudget: number,     // 总预算Token
  utilization: number,     // 总利用率
  layers: {
    [layer]: {
      usage: number,       // 层使用量
      budget: number,      // 层预算
      utilization: number, // 层利用率
      loadedItems: number, // 已加载项数
      priority: number,    // 优先级
    }
  }
}
```

### `getRecommendations()`

获取优化建议。

**返回值**：`Array<{layer, action, reason, suggestedReclaim?|suggestedIncrease?}>`

**建议规则**：
- 层利用率 > `dangerThreshold`（默认95%）：建议减少，建议回收30%使用量
- 高优先级层（≥3）利用率 < 30%：建议扩展，建议增加20%预算

### `getStats()`

获取统计信息。

**返回值**：

```javascript
{
  totalAllocations: number,
  totalRejections: number,
  totalReclaims: number,
  totalUsed: number,
  totalBudget: number,
  layerStats: {
    [layer]: {
      allocations: number,
      rejections: number,
      reclaims: number,
      peakUsage: number,
    }
  }
}
```

## 导出常量

### FEATURE_LAYERS

特性层级标识，定义5层上下文成本层级。

| 属性 | 值 | 说明 |
|------|---|------|
| `PROJECT_MEMORY` | `'project_memory'` | 项目记忆层（CLAUDE.md等价），最高成本 |
| `SKILLS` | `'skills'` | 技能包层，高成本 |
| `MCP` | `'mcp'` | MCP外部连接层，中等成本 |
| `SUBAGENTS` | `'subagents'` | 子Agent并行处理层，低成本 |
| `HOOKS` | `'hooks'` | Hook事件自动化层，最低成本 |

### LAYER_PRIORITY

层级优先级映射，数值越高优先级越高。

| 层级 | 优先级 |
|------|--------|
| `project_memory` | 5 |
| `skills` | 4 |
| `mcp` | 3 |
| `subagents` | 2 |
| `hooks` | 1 |

### LAYER_DEFAULT_BUDGET_RATIO

各层默认预算分配比例。

| 层级 | 比例 | 说明 |
|------|------|------|
| `project_memory` | 0.35 | 35%分配给项目记忆 |
| `skills` | 0.25 | 25%分配给技能包 |
| `mcp` | 0.20 | 20%分配给MCP连接 |
| `subagents` | 0.12 | 12%分配给子Agent |
| `hooks` | 0.08 | 8%分配给Hook |

## 事件列表

| 事件名 | 触发时机 | 数据 |
|--------|---------|------|
| `item-loaded` | 特性项加载成功 | `{layer, itemId, tokenCount, totalUsed}` |
| `item-unloaded` | 特性项卸载 | `{layer, itemId, tokenCount, totalUsed}` |
| `budget-exceeded` | 预算不足 | `{layer, itemId, estimatedTokens/tokenCount, currentUsage, budget}` |
| `budget-reclaimed` | 预算回收 | `{layer, reclaimed, totalUsed}` |
| `budgets-reallocated` | 预算重分配 | `{budgets: Object}` |
| `budget-warning` | 总利用率达警告阈值 | `{utilization, totalUsed, totalBudget}` |
| `budget-danger` | 总利用率达危险阈值 | `{utilization, totalUsed, totalBudget}` |

## 使用示例

### 基本用法

```javascript
const { ContextBudgetOptimizer, FEATURE_LAYERS } = require('./src/runtime/infrastructure/context-budget-optimizer');

const optimizer = new ContextBudgetOptimizer({
  maxContextTokens: 200000,
  warningThreshold: 0.8,
  dangerThreshold: 0.95,
});

// 检查是否可以加载
if (optimizer.canLoad(FEATURE_LAYERS.SKILLS, 'tdd-skill', 5000)) {
  optimizer.registerLoad(FEATURE_LAYERS.SKILLS, 'tdd-skill', 5000);
}

// 加载项目记忆
optimizer.registerLoad(FEATURE_LAYERS.PROJECT_MEMORY, 'claude-md', 15000);
```

### 阈值告警

```javascript
optimizer.on('budget-warning', ({ utilization, totalUsed, totalBudget }) => {
  console.warn(`上下文利用率警告: ${(utilization * 100).toFixed(1)}% (${totalUsed}/${totalBudget})`);
});

optimizer.on('budget-danger', ({ utilization, totalUsed, totalBudget }) => {
  console.error(`上下文利用率危险: ${(utilization * 100).toFixed(1)}% (${totalUsed}/${totalBudget})`);
});
```

### 预算回收与重分配

```javascript
// 从低优先级层回收预算
const reclaimed = optimizer.reclaimFromLayer(FEATURE_LAYERS.HOOKS, 3000);
console.log(`回收了 ${reclaimed} tokens`);

// 根据使用模式重分配预算
optimizer.reallocateBudgets({
  [FEATURE_LAYERS.PROJECT_MEMORY]: 0.4,  // 增加项目记忆预算
  [FEATURE_LAYERS.SKILLS]: 0.3,
  [FEATURE_LAYERS.MCP]: 0.15,
  [FEATURE_LAYERS.SUBAGENTS]: 0.1,
  [FEATURE_LAYERS.HOOKS]: 0.05,
});
```

### 获取状态与建议

```javascript
const status = optimizer.getBudgetStatus();
console.log(`总利用率: ${(status.utilization * 100).toFixed(1)}%`);
for (const [layer, info] of Object.entries(status.layers)) {
  console.log(`  ${layer}: ${info.usage}/${info.budget} (${(info.utilization * 100).toFixed(1)}%)`);
}

const recommendations = optimizer.getRecommendations();
for (const rec of recommendations) {
  console.log(`建议 [${rec.layer}]: ${rec.action} - ${rec.reason}`);
}
```

### 卸载特性项

```javascript
optimizer.unregisterLoad(FEATURE_LAYERS.SKILLS, 'tdd-skill', 5000);
console.log('技能已卸载，预算已释放');
```

## 与其他模块的关系

- **依赖**：`events`（Node.js内置） — EventEmitter基类
- **依赖**：`../../utils/shutdown-mixin.js` — 优雅关闭
- **依赖**：`../../utils/safe-execute.js` — 安全调用

- **被依赖**：SharedInfrastructure — 作为上下文预算管理的核心组件

- **协作**：DynamicAgentSpawner — 子Agent生成时通过预算优化器检查上下文配额
