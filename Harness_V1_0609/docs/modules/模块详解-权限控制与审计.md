# 模块详解 — 权限控制与审计

> 版本：2.73.4
> 路径：`src/permission/`
> 核心文件：rbac-enforcer.js、permission-guard.js、audit-logger.js
> 核心职责：基于角色的访问控制（RBAC）、文件/命令安全守卫、链式哈希审计日志

---

## 概述

权限控制与审计模块群是 Harness 框架的安全核心，实现了"授权→守卫→审计"的完整安全闭环。三个模块分工明确：RBACEnforcer 负责基于角色的访问控制，解决"谁能做什么"的权限判定问题；PermissionGuard 负责文件操作和命令执行的安全守卫，解决"操作是否安全"的运行时检查问题；AuditLogger 负责所有权限决策的链式哈希审计记录，解决"做了什么留痕"的合规追溯问题。

## 关键能力

- **RBAC 访问控制**（RBACEnforcer）：从 `.harness/agents/` 和 `.harness/skills/` 加载权限定义，实现双向权限验证——既检查 Agent 是否有权执行某 Skill，也检查 Skill 是否允许某 Agent 执行。支持 `strict`/`recommended`/`optional` 三级执行级别，以及基于 Agent 模型的能力约束验证。
- **安全守卫**（PermissionGuard）：提供文件路径安全检查（路径遍历防护、工作区边界约束）、文件操作确认过期管理、危险命令黑名单检测和文件锁冲突检测，确保所有运行时操作均在工作区边界内且通过安全审查。
- **链式哈希审计**（AuditLogger）：所有权限决策（通过/拒绝/确认）均写入不可篡改的链式哈希审计日志，每条记录包含前一条的哈希值，支持完整性和防篡改验证。提供按时间/Agent/Skill/操作类型的多维度查询和统计导出能力。

## 框架集成

权限控制与审计模块群在Agent执行链路中位于关键路径：所有Agent的Skill调用和文件操作必须先通过 RBACEnforcer 的 `canExecute()` 权限判定，再通过 PermissionGuard 的运行时安全检查，二者均通过后操作才被执行。审计日志贯穿全链路——RBACEnforcer 和 PermissionGuard 的每一次决策均自动记录至 AuditLogger。该模块群与 AgentRuntime（Agent 运行时）、SubagentExecutor（子Agent执行器）和 SkillRouter（技能路由）紧密集成，为多Agent协作环境提供细粒度的权限管控和完整的审计追踪能力。
