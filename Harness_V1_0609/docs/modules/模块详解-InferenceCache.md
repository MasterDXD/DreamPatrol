# 模块详解：InferenceCache（推理缓存）

> 源码路径：`src/runtime/model/inference-cache.js` | 版本：2.73.4

## 概述

InferenceCache 为 LLM 推理提供缓存层，通过 LRU 策略缓存推理结果，减少重复请求的 API 调用成本和延迟。支持语义级和精确匹配两种缓存模式。

## 核心功能

### 缓存策略
- LRU（最近最少使用）淘汰策略
- 可配置缓存容量

### 匹配模式
- **精确匹配**：相同 prompt 直接返回缓存
- **语义匹配**：基于 embedding 相似度的模糊匹配

### 统计监控
- 缓存命中率追踪
- Token 节省量统计

## 配置选项

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `maxSize` | `1000` | 最大缓存条目数 |
| `ttl` | `3600000` | 缓存过期时间（ms） |
