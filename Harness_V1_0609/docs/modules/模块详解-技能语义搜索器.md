# 模块详解-技能语义搜索器

> 版本：2.73.4 | 文件：src/runtime/skill/skill-semantic-searcher.js | 融合来源：find-skills向量嵌入语义搜索

---

## 概述

技能语义搜索器（SkillSemanticSearcher）融合了find-skills的向量嵌入语义搜索核心能力，补齐Harness技能发现子系统的语义搜索空白。原有SkillRouter的语义匹配基于关键词包含（SEMANTIC_GROUPS分组匹配），无法理解语义相似性；本模块通过向量嵌入驱动的模糊搜索，实现真正的语义级别技能发现。

### 解决的问题

| 问题 | 原有方案 | 本模块方案 |
|------|---------|-----------|
| 语义匹配能力不足 | SkillRouter基于关键词包含匹配，无法理解"重构"与"代码优化"的语义关联 | 向量嵌入计算语义相似度，支持模糊语义匹配 |
| 缺少向量嵌入驱动搜索 | 无向量嵌入基础设施，搜索依赖文本精确匹配 | 集成EmbeddingService，构建技能语义索引 |
| 相似技能发现困难 | 无法基于语义相似度查找相关技能 | findSimilar()基于向量距离发现相似技能 |

### 融合策略

| 维度 | 评估结果 | 融合方案 |
|------|---------|---------|
| 向量嵌入 | 核心特性，高度匹配 | 原生集成EmbeddingService |
| 语义索引 | 高度匹配 | 原生Node.js实现，BoundedMap存储 |
| 关键词回退 | 必需，兼容现有系统 | 无嵌入服务时自动回退到关键词匹配 |
| 增量更新 | 中等匹配 | 定时索引刷新 + 手动触发重建 |

## 常量

### DEFAULT_SEMANTIC_SEARCH_CONFIG

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| embeddingDimension | `384` | 嵌入向量维度 |
| similarityThreshold | `0.6` | 语义相似度阈值，低于此值的结果被过滤 |
| maxResults | `10` | 单次搜索最大返回结果数 |
| indexUpdateIntervalMs | `60000` | 索引自动刷新间隔（毫秒） |

### SIMILARITY_METRICS

| 度量 | 值 | 说明 |
|------|-----|------|
| COSINE | `'cosine'` | 余弦相似度（默认） |
| EUCLIDEAN | `'euclidean'` | 欧几里得距离 |
| DOT_PRODUCT | `'dot_product'` | 点积相似度 |

## 类定义

```javascript
class SkillSemanticSearcher extends EventEmitter {
  constructor(options)
  attachEmbeddingService(service)
  attachSkillRouter(router)
  buildIndex()
  search(query, options)
  findSimilar(skillId, options)
  compareSkills(skillIds)
  getStats()
  shutdown() // via withShutdown mixin
}
```

---

## 构造函数

```javascript
const searcher = new SkillSemanticSearcher({
  embeddingDimension: 384,
  similarityThreshold: 0.6,
  maxResults: 10,
  indexUpdateIntervalMs: 60000,
});
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `embeddingDimension` | number | `384` | 嵌入向量维度，需与EmbeddingService一致 |
| `similarityThreshold` | number | `0.6` | 语义相似度阈值，范围0-1 |
| `maxResults` | number | `10` | 单次搜索最大返回数 |
| `indexUpdateIntervalMs` | number | `60000` | 索引自动刷新间隔（毫秒），0则禁用自动刷新 |

## 核心属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `_embeddingService` | EmbeddingService \| null | 嵌入服务实例，通过attachEmbeddingService()注入 |
| `_skillRouter` | SkillRouter \| null | SkillRouter实例，通过attachSkillRouter()注入 |
| `_index` | BoundedMap | 语义索引，skillId → 嵌入向量映射 |
| `_indexTimer` | Timer \| null | 索引自动刷新定时器 |
| `_stats` | Object | 运行统计信息 |

## 方法详解

### attachEmbeddingService(service)

挂载嵌入服务。注入EmbeddingService实例后，搜索器可使用向量嵌入进行语义搜索。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `service` | EmbeddingService | 嵌入服务实例，需提供`embed(text)`方法 |

**返回：** `SkillSemanticSearcher` — 支持链式调用

---

### attachSkillRouter(router)

挂载SkillRouter。注入SkillRouter后，搜索器可获取技能列表用于构建语义索引。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `router` | SkillRouter | SkillRouter实例，需提供`skills`属性 |

**返回：** `SkillSemanticSearcher` — 支持链式调用

---

### buildIndex()

构建语义索引。遍历SkillRouter中的所有技能，为每个技能生成嵌入向量并存入索引。

**逻辑：**
1. 检查EmbeddingService和SkillRouter是否已挂载
2. 遍历`skillRouter.skills`，对每个技能的`name + summary`生成嵌入向量
3. 将`{skillId, embedding, metadata}`存入`_index`（BoundedMap）
4. 更新统计信息

**返回：** `{ indexed: number, skipped: number, errors: number }`

---

### search(query, options)

语义搜索。根据查询文本在技能索引中搜索语义相似的技能。无嵌入服务时自动回退到关键词匹配。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `query` | string | 查询文本 |
| `options` | Object | 可选配置 |
| `options.similarityThreshold` | number | 覆盖默认相似度阈值 |
| `options.maxResults` | number | 覆盖默认最大返回数 |
| `options.metric` | string | 相似度度量方式（cosine/euclidean/dot_product） |

**返回：** `Array<{ skillId, score, metadata }>`

**回退逻辑：**
- 无EmbeddingService → 使用关键词匹配：将query分词后与技能name/summary进行关键词包含匹配
- 无SkillRouter → 返回空数组

---

### findSimilar(skillId, options)

查找与指定技能语义相似的其他技能。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `skillId` | string | 目标技能ID |
| `options` | Object | 可选配置（同search的options） |

**返回：** `Array<{ skillId, score, metadata }>` — 不包含自身

**逻辑：** 从索引中获取目标技能的嵌入向量，与所有其他技能的嵌入向量计算相似度，按分数降序排列。

---

### compareSkills(skillIds)

多技能对比。对指定技能列表进行两两语义相似度对比。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `skillIds` | string[] | 待对比的技能ID列表 |

**返回：** `Array<{ skillA, skillB, similarity }>`

---

### getStats()

获取统计信息。

**返回：**

```javascript
{
  indexSize: number,           // 索引中的技能数
  totalSearches: number,       // 总搜索次数
  totalFallbacks: number,      // 回退到关键词匹配的次数
  avgSearchTimeMs: number,     // 平均搜索耗时
  lastIndexBuildAt: number,    // 上次索引构建时间
  embeddingServiceAttached: boolean,  // 嵌入服务是否已挂载
  skillRouterAttached: boolean,       // SkillRouter是否已挂载
}
```

## 事件

| 事件名 | 触发时机 | 数据 |
|--------|---------|------|
| `index-built` | 索引构建完成 | `{ indexed, skipped, errors }` |
| `search-complete` | 搜索完成 | `{ query, results, timeMs, fallback }` |
| `similar-found` | 相似技能发现 | `{ skillId, similar, count }` |

## 使用示例

### 基本语义搜索

```javascript
const SkillSemanticSearcher = require('./src/runtime/skill/skill-semantic-searcher');

const searcher = new SkillSemanticSearcher({
  embeddingDimension: 384,
  similarityThreshold: 0.6,
  maxResults: 10,
});

// 挂载依赖
searcher
  .attachEmbeddingService(embeddingService)
  .attachSkillRouter(skillRouter);

// 构建索引
const buildResult = searcher.buildIndex();
console.log(`已索引 ${buildResult.indexed} 个技能`);

// 语义搜索
const results = searcher.search('代码质量优化与重构');
results.forEach(r => {
  console.log(`${r.skillId}: ${r.score.toFixed(3)}`);
});
```

### 查找相似技能

```javascript
// 查找与tdd-implement语义相似的技能
const similar = searcher.findSimilar('tdd-implement', {
  similarityThreshold: 0.5,
  maxResults: 5,
});
similar.forEach(r => {
  console.log(`${r.skillId}: 相似度 ${r.score.toFixed(3)}`);
});
```

### 多技能对比

```javascript
// 对比多个技能的语义相似度
const comparisons = searcher.compareSkills([
  'tdd-implement',
  'code-review',
  'integration-testing',
]);
comparisons.forEach(c => {
  console.log(`${c.skillA} ↔ ${c.skillB}: ${c.similarity.toFixed(3)}`);
});
```

### 无嵌入服务时自动回退

```javascript
// 未挂载EmbeddingService时，自动回退到关键词匹配
const searcher = new SkillSemanticSearcher();
searcher.attachSkillRouter(skillRouter);
searcher.buildIndex();

const results = searcher.search('测试驱动开发');
// 结果基于关键词包含匹配，score字段反映关键词匹配度
```

## 与其他模块的集成

| 模块 | 集成方式 | 说明 |
|------|---------|------|
| SkillRouter | 依赖注入 | 通过attachSkillRouter()注入，获取技能列表 |
| EmbeddingService | 依赖注入 | 通过attachEmbeddingService()注入，生成嵌入向量 |
| BoundedMap | 直接使用 | 语义索引存储，支持容量限制 |
| shutdown-mixin | 继承 | 使用withShutdown混入，支持优雅关闭 |

---

## 关闭行为

`shutdown()` 执行以下清理操作：

1. 清空嵌入向量索引（`_index`）
2. 停止索引自动刷新定时器（`_indexTimer`）
3. 关闭BoundedMap（`_index.shutdown()`）
4. 置空EmbeddingService和SkillRouter引用
