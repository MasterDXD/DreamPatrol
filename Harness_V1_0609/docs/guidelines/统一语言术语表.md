# 统一语言术语表 (Ubiquitous Language)

本文档定义了 Harness 框架核心概念的标准化术语，确保开发团队和领域专家使用一致的语言。

## 技能域 (Skill Domain)

| 术语 | 英文 | 定义 | 代码映射 |
|------|------|------|---------|
| 技能 | Skill | 系统可执行的能力单元，包含输入/输出定义和执行逻辑 | `SkillRouter`, `SkillGraph` |
| 技能路由 | Skill Routing | 根据用户意图匹配最优技能的过程 | `SkillRouter._route()` |
| 技能演化 | Skill Evolution | 技能通过经验积累自动改进的过程 | `SkillEvolver` |
| 技能蒸馏 | Skill Distillation | 将复杂技能简化为高效子技能的过程 | `SkillDistiller` |
| 技能图谱 | Skill Graph | 技能间依赖和关联关系的有向无环图 | `SkillGraph`, `SkillTreeDAG` |

---

## 术语使用规范

1. **一致性**：同一概念在代码、文档、API中必须使用相同术语
2. **精确性**：避免使用模糊术语（如"东西""那个"），必须使用术语表中的标准术语
3. **中英对照**：首次出现时提供中英文对照，后续使用中文术语
4. **代码映射**：每个术语必须能追溯到具体的代码模块或类
