## 13.1 Cursor

| 策略 | 说明 | 示例 |
|------|------|------|
| 使用@file引用 | 让AI看到具体文件 | `@src/services/auth.ts` |
| 使用@folder引用 | 让AI理解目录结构 | `@src/components/` |
| 使用@docs引用 | 让AI参考项目文档 | `@docs/api.md` |
| 使用@Web搜索 | 让AI搜索最新信息 | `@Web latest Next.js 15 features` |
| Cmd+K内联编辑 | 选中代码后直接修改，比聊天更高效 | 选中函数→Cmd+K→输入修改指令 |
| Composer模式 | 多文件同时编辑，适合大范围重构 | Cmd+I→描述跨文件修改 |
| .cursorrules文件 | 项目级指令，自动注入到每次对话 | 见模块11 |
| Notepad | 保存重要上下文供后续对话使用 | 存储架构决策、API设计 |

**Cursor专属提示词技巧：**
```
@src/services/auth.ts @src/types/user.ts

请基于以上文件中的现有模式，在 src/services/order.ts 中实现 OrderService。
遵循 AuthService 的错误处理模式和 UserService 的类型定义风格。
```

## 13.3 Claude Code / Claude

| 策略 | 说明 |
|------|------|
| 使用XML标签 | `<instructions>`, `<code>`, `<constraints>`结构化输入 |
| 告诉它"为什么" | 解释约束背后的原因，Claude理解后表现更好 |
| 扩展思维模式 | 复杂问题开启extended thinking，让Claude展示推理过程 |
| 明确说"做"而非"建议" | "直接修改文件"而非"建议如何修改" |
| CLAUDE.md文件 | 项目级指令，每次对话自动加载 |
| 长上下文 | 利用200K上下文窗口，一次性提供大量相关代码 |

**Claude专属提示词技巧：**
```xml
<task>
重构用户认证模块，从session-based迁移到JWT
</task>

<current_implementation>
{粘贴当前代码}
</current_implementation>

<requirements>
1. 保持所有现有API端点不变
2. 添加refresh token轮换机制
3. 支持token黑名单（用于登出功能）
4. 向后兼容：支持1周的过渡期，同时接受session和JWT
</requirements>

<constraints>
- 使用 jsonwebtoken 库（已在项目中）
- 不要引入新的认证相关依赖
- 所有密钥从环境变量读取
</constraints>

<reference>
{粘贴项目中类似的JWT实现代码}
</reference>
```

## 关键要点

1. **每个工具有专属优化策略**——Cursor用@引用，Claude用XML标签，Copilot靠注释
2. **项目级配置是所有工具的共同最佳实践**——.cursorrules/CLAUDE.md/copilot-instructions.md
3. **Cursor的@引用是最强大的上下文提供方式**——直接让AI看到代码
4. **Claude的XML标签是最结构化的输入方式**——明确分隔指令与数据
