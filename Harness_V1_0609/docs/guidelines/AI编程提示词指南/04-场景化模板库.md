## 4.10 安全审计

```
你是一位网络安全专家，请对以下代码进行安全审计：

关注点：
1. 注入攻击（SQL注入、XSS、命令注入）
2. 认证与授权漏洞
3. 敏感数据泄露
4. 不安全的加密/哈希
5. 竞态条件
6. 输入验证不足

对每个发现的安全问题：
- 严重程度：Critical / High / Medium / Low
- 攻击场景描述
- 修复建议（含代码示例）

{粘贴代码}
```

---

## 关键要点

1. **10个模板覆盖编程全场景**——从代码生成到安全审计
2. **每个模板都包含约束**——防止AI自由发挥
3. **Bug修复模板强调"根因分析"**——不只修表面症状
4. **重构模板必须包含"保持逻辑不变"**——防止AI自作聪明
5. **模板可组合使用**——如"代码审查"+"安全审计"组合
