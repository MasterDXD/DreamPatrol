# /prompt — AI编程提示词工程

## 使用场景
- 代码生成质量不佳，需要优化提示词
- AI输出存在幻觉或不一致
- 需要创建可复用的提示词模板
- 跨模型适配提示词

## 执行流程
1. 激活 ai-prompting Skill — AI编程提示词工程
2. 分析当前提示词的问题
3. 应用优化策略（结构化、防幻觉、模板化）
4. 验证优化效果

## 交付物
- 优化后的提示词
- 提示词模板（可复用）
- 优化效果对比说明
