# /startup — AI创业流程

## 使用场景
- 创业者有一个想法，需要从零开始验证和构建
- 非技术创始人希望借助AI独立构建产品
- 现有产品需要制定AI原生的规模化策略
- 需要系统性地评估商业假设的可行性

## 执行流程

### 阶段1：想法探索与验证
1. **brainstorming** — 苏格拉底式提问，探索想法的核心假设
2. **idea-validation** — 构建假设矩阵，扫描竞争格局，量化不确定性
   - 不确定性 > 0.7 → 回退重新探索
   - 不确定性 0.4-0.7 → 小规模实验
   - 不确定性 < 0.4 → 进入下一阶段

### 阶段2：需求分析与架构设计
3. **requirement-analysis** — 将验证通过的想法转化为需求规格
4. **architecture-design** — 设计系统架构，定义接口契约

### 阶段3：MVP构建与发布
5. **mvp-builder** — AI辅助快速构建MVP（架构先行、边界清晰、安全优先）
6. **deployment** — 部署上线，验证PMF信号

### 阶段4：AI原生规模化
7. **ai-native-scaling** — 制定AI优先扩展路径，构建自动化运营系统

## 交付物
| 阶段 | 交付物 |
|------|--------|
| 想法验证 | 假设验证矩阵、竞争格局分析、不确定性评分 |
| 需求架构 | 需求规格说明书、系统架构文档 |
| MVP构建 | 可运行应用、测试报告、技术债登记册 |
| 规模化 | 规模化策略、自动化蓝图、增长模型 |

## 关键决策点
1. **GO/NO-GO/PIVOT** — 想法验证后的方向决策
2. **MVP范围确认** — 核心功能集与"不做"清单
3. **PMF确认** — 产品发布后的市场匹配验证
4. **规模化就绪** — 是否具备非线性增长条件
