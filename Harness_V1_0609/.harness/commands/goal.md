# /goal — 持久长期目标执行

## 功能说明

将AI从"每次只能执行一条指令的工具"升级为"能够持续推进长期工程目标的自主智能体"。

开发者只需设定宏观目标，AI可跨越多次交互和中断，自主迭代直至目标完成或遇阻。

## 使用方式

### 设定新目标
```
/goal 实现用户认证系统，包含注册、登录、密码重置功能
```

### 查看目标进度
```
/goal status
```

### 暂停目标
```
/goal pause
```

### 恢复目标
```
/goal resume
```

### 取消目标
```
/goal cancel
```

### 列出所有目标
```
/goal list
```

## 执行流程

1. **目标解析**：理解用户设定的宏观目标，提取成功标准和约束
2. **自动拆解**：将宏观目标分解为多个可执行子步骤
3. **自主迭代**：循环执行"编码→运行→检查→修复"流程
4. **收敛检测**：每轮迭代评估质量分数，达标则停止
5. **防漂移注入**：每轮迭代重新注入原始目标，防止偏离
6. **进度报告**：实时报告目标进度、子任务完成情况

## 核心能力

- **自动拆解任务**：将宏观目标分解为多个可执行子步骤
- **自主迭代**：循环执行"编码→运行→检查→修复"流程，直至目标达成
- **任务管理**：开发者可随时对运行中的目标进行暂停、恢复或清除操作
- **跨会话持久化**：目标状态持久化到磁盘，进程重启后自动恢复
- **防漂移机制**：每轮迭代注入原始目标，防止长期执行中偏离

## 成功标准格式

建议在目标中包含可验证的成功标准：
```
/goal 实现登录功能
  成功标准：
  - 用户可以使用邮箱和密码注册
  - 用户可以使用注册的凭据登录
  - 登录失败时显示错误提示
  - 密码重置邮件可以正常发送
```

## 注意事项

- 目标设定应具体且可验证，避免模糊描述
- 复杂目标建议分阶段设定，每阶段独立验证
- 长时间运行的目标会自动持久化，可安全中断
- 目标状态保存在 .harness/goals/ 目录下
