# /plan — 实现规划

## 使用场景
- 开始新项目时，需要从模糊想法提炼清晰需求
- 需要制定完整的项目实现方案
- 需要系统化地分析需求和设计架构

## 执行流程
1. 激活 brainstorming Skill — 苏格拉底式提问探索需求
2. 激活 requirement-analysis Skill — 结构化需求分析
3. 激活 architecture-design Skill — 系统架构设计

## 交付物
- 需求规格说明书
- 架构设计文档
- 项目计划书
