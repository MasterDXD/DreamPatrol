## 1. 产品概述

### 1.1 产品背景

梦境是一种稍纵即逝的私密体验——大多数人醒来后只能记住零碎片段，更难以描述梦中复杂且微妙的情绪感受。市面上虽不乏笔记类工具，但它们普遍缺乏对"梦"这一特殊场景的深度适配：无法承载梦的模糊性、非线性叙事特征，更无法在用户回顾梦境时提供情绪上的共鸣与安放。

**「巡梦」** 应运而生——它不是一本普通的记事本，而是一个专为"做梦"而生的沉浸式梦境空间。

### 1.2 产品定位

> **一个以"情绪承接"为核心的梦境记录与管理 Web 应用。**

- **关键词**：梦境、记录、回顾、情绪、沉浸、共鸣
- **核心差异**：不同于通用笔记工具，"巡梦"围绕梦境的非线性、情绪化特征进行设计，让用户在记录和回顾梦境时获得"被理解、被安放"的感受。

### 1.3 产品愿景

让每一个梦都被温柔安放。帮助用户：
- **留住梦**——多渠道快速录入，不错过每一个梦的细节；
- **回看梦**——以时间线、日历等视角重新审视自己的梦境历程；
- **感受梦**——在回溯梦境时，通过视觉、氛围和情绪映射，获得深层次的共鸣体验。

### 1.4 核心设计原则

| 原则 | 说明 |
|------|------|
| **情绪优先** | 每一个交互决策都以用户情绪体验为出发点，而非功能堆砌 |
| **轻盈不打扰** | 界面克制、操作流畅，不给刚醒来的用户制造认知负担 |
| **沉浸式承接** | 视觉氛围随梦境内容与情绪动态变化，营造"进入梦境"的沉浸感 |
| **可靠安心** | 数据持久化、会话隔离，用户无需担心梦境丢失或混淆 |

### 1.5 项目约束

- **时间约束**：单日冲刺，从开题（08:30）到提交（16:30），约 8 小时；
- **交付物**：GitHub 仓库（含项目介绍）、3-6 分钟演示视频、100 字产品介绍；
- **演示要求**：可现场流畅演示的稳定版本（本地/内网/公网均可）；
- **参赛形式**：可个人或组队。

## 2. 目标用户分析

### 2.1 用户画像

#### 画像 A：梦境探索者

| 维度 | 描述 |
|------|------|
| **特征** | 频繁做梦、对梦境内容有强烈好奇心，希望通过记录发现潜意识规律 |
| **痛点** | 醒来后梦快速消散，尝试用手机备忘录记录但体验割裂 |
| **核心诉求** | 快速捕捉碎片，分类整理，发现梦与生活的关联 |
| **使用场景** | 每天醒来第一件事：记录昨晚的梦 |

#### 画像 B：情绪敏感者

| 维度 | 描述 |
|------|------|
| **特征** | 梦境伴随强烈情绪（恐惧、悲伤、喜悦、怀念），需要一个安全的情绪出口 |
| **痛点** | 梦中情绪难以言说，普通文字无法承载感受的厚度 |
| **核心诉求** | 情绪标记、氛围营造、解读反馈，获得"被接住"的感觉 |
| **使用场景** | 做了印象深刻的梦后，需要一个空间安放这些情绪 |

#### 画像 C：好奇体验者

| 维度 | 描述 |
|------|------|
| **特征** | 对做梦这件事感兴趣，偶尔记录，更多是出于新鲜感和探索欲 |
| **痛点** | 缺少动力持续记录，普通 App 功能太重 |
| **核心诉求** | 低门槛上手、有仪式感的记录体验 |
| **使用场景** | 被推荐/看到后，偶尔打开记录有趣的梦 |

### 2.2 用户核心场景

| 编号 | 场景 | 情绪状态 | 核心需求 |
|------|------|----------|----------|
| S1 | 清晨刚醒，迷迷糊糊记录昨晚的梦 | 朦胧、半醒 | 极低操作门槛，语音/快速输入 |
| S2 | 午后回想，补全梦境细节 | 清醒、专注 | 文本编辑、细节补充 |
| S3 | 周末回顾，浏览近期梦境 | 放松、好奇 | 日历浏览、时间线翻阅 |
| S4 | 被某个梦触动，想重温那段情绪 | 感性、沉浸 | 沉浸式回看，情绪氛围 |
| S5 | 和朋友分享有趣的梦 | 兴奋、分享欲 | 分享/导出能力（可选扩展） |

## 3. 核心功能模块设计

### 3.1 功能总览

```
┌─────────────────────────────────────────────────┐
│                    巡梦                          │
├───────────────┬───────────────┬─────────────────┤
│   梦境记录     │   梦境管理     │   情绪承接       │
│  (Record)     │  (Manage)     │  (Emotion)      │
├───────────────┼───────────────┼─────────────────┤
│ · 文本录入    │ · 列表视图    │ · 情绪标记       │
│ · 语音录入    │ · 日历视图    │ · 氛围可视化     │
│ · 草稿保存    │ · 详情查看    │ · 梦境标签云     │
│               │ · 搜索筛选    │ · 情绪统计       │
├───────────────┴───────────────┴─────────────────┤
│              基础设施 (Infrastructure)            │
│    数据持久化 / 会话隔离 / 错误处理 / 响应式      │
└─────────────────────────────────────────────────┘
```

### 3.2 模块一：梦境记录（必做）

#### 3.2.1 文本录入

- **富文本输入**：提供简洁、大面积的文本输入区域，适配刚醒时的"朦胧"状态；
- **Placeholder 文案**：使用温暖的引导语，如"昨晚，你梦见了什么…"；
- **字数统计**：温和提示（非限制），鼓励但不强迫；
- **自动保存草稿**：防止意外退出丢失内容，每隔 30 秒自动保存至 localStorage。

#### 3.2.2 语音录入（第二录入方式）

- **核心设计**：用户点击麦克风按钮，实时语音转文字，自动填入输入框；
- **实现方案**：使用浏览器 Web Speech API（SpeechRecognition）；
- **降级策略**：不支持语音识别的浏览器自动隐藏该入口；
- **交互细节**：
  - 长按录制，松开停止（移动端友好）；
  - 录制时显示动态波形动画，增强"捕捉梦境"的仪式感；
  - 语音转写结果追加到文本框，不会覆盖已有内容。

#### 3.2.3 梦境提交

- **提交按钮**：醒目的主操作按钮，如"留下这个梦"；
- **过渡动画**：提交时配合微妙的星尘/粒子动效，象征"梦被安放"；
- **提交后行为**：反馈成功提示（轻量 Toast），自动跳转至梦境列表/日历。

### 3.3 模块二：梦境管理（必做）

#### 3.3.1 梦境列表视图

- **设计方向**：卡片式布局，每条梦境以独立卡片呈现；
- **卡片内容**：
  - 梦境标题（自动截取前 N 字或用户自定义）
  - 梦境内容预览（最多 2 行截断）
  - 记录日期与时间
  - 情绪标签（以色彩圆点或表情呈现）
- **排序**：按时间倒序（最新在前）；
- **空状态**：当无梦境时，展示温馨的插画引导，如"还没有梦被留下，去记录你的第一个梦吧"。

#### 3.3.2 日历视图（必做）

- **实现方式**：月视图日历组件；
- **核心交互**：
  - 日历格子上有梦境的日期显示标记点（小圆点，颜色对应情绪）；
  - 点击日期弹出当日梦境列表（Popover 或底部抽屉）；
  - 点击具体梦境进入详情页；
  - 支持月份切换（左右箭头）；
- **视觉增强**：有梦的日期使用渐变/柔和色彩区分于空白日期，形成"梦境星图"的视觉隐喻。

#### 3.3.3 梦境详情页

- **全屏沉浸式阅读**：最大化内容展示，减少 UI 干扰；
- **氛围背景**：根据梦境关联的情绪动态切换背景色/渐变（如：喜悦→暖金色，悲伤→蓝紫色，恐惧→暗灰色）；
- **操作项**：返回、编辑、删除（需二次确认）。

#### 3.3.4 搜索与筛选（可选扩展）

- 关键字搜索梦境内容；
- 按情绪标签筛选；
- 按时间范围筛选。

### 3.4 模块三：情绪承接（必做，至少一种）

#### 3.4.1 情绪标记（核心必选）

- **设计**：在记录梦境时/提交前，用户选择/标注梦境的主导情绪；
- **可选情绪**（不宜过多，减少选择负担）：

  | 情绪 | 视觉隐喻 | 代表色 |
  |------|----------|--------|
  | 喜悦 | 阳光/暖光 | 暖金 #F5A623 |
  | 平静 | 湖水/月光 | 淡蓝 #7EC8E3 |
  | 悲伤 | 雨夜/暮色 | 蓝紫 #6C63FF |
  | 恐惧 | 迷雾/暗影 | 暗灰 #4A4A4A |
  | 奇妙 | 星空/幻境 | 紫粉 #E040FB |
  | 怀念 | 旧照片/黄昏 | 暖橙 #FF8A65 |

- **交互**：情绪选择器以柔和图标 + 文字呈现，选中后高亮，赋予用户"标记情绪"的仪式感。

#### 3.4.2 氛围可视化（增强体验）

- **列表页**：梦境卡片背景色调跟随情绪标签；
- **详情页**：全屏氛围背景，以 CSS 渐变 + 微粒子动效营造沉浸感；
- **日历页**：日期标记点颜色映射情绪，整体形成"情绪星图"；
- **全局情绪统计**：以简洁的环形图/条形图展示梦境的情绪分布（可选扩展）。

#### 3.4.3 情绪解读/反馈（可选扩展）

- 根据用户标记的情绪，在详情页展示一句温柔的回应用语（预置文案库）。
- 示例："这个梦似乎带着一丝忧伤。梦是心灵的密语，它在替你诉说那些白天无法言说的话。"

## 5. 信息架构

### 5.1 页面层级结构

```
巡梦 (DreamPatrol)
│
├── 页面 1：首页 / 梦境列表 (Home/List)

│   ├── 梦境卡片列表 (按时间倒序)
│   │   ├── 卡片：情绪色条 | 标题 | 内容预览 | 日期 | 标签
│   │   └── 空状态：引导插画 + "记录你的第一个梦"

├── 页面 2：新建梦境 (New Dream)
│   ├── 文本输入区 (大面积 Textarea，自动聚焦)

│   ├── 全屏氛围背景 (情绪色渐变 + 粒子动效)
│   ├── 梦境内容 (全文本展示)
│   ├── 日期 + 情绪标签
│   ├── 情绪回应语 (可选)
│   └── 操作区：返回 | 编辑 | 删除
│
├── 页面 4：日历视图 (Calendar)
│   ├── 月视图日历
│   │   ├── 月份切换 (← →)
│   │   ├── 日期格子 + 情绪标记点

│   └── 返回首页
│
└── 页面 5：编辑页面 (复用新建页面，预填内容)
```

### 5.2 数据结构设计

```typescript
// 梦境核心数据结构
interface Dream {
  id: string;                // 唯一标识 (UUID)
  userId: string;            // 用户标识 (用于数据隔离)
  title: string;             // 梦境标题 (自动截取或用户自定义)
  content: string;           // 梦境内容 (纯文本)
  emotion: EmotionType;      // 主导情绪
  createdAt: string;         // 创建时间 (ISO 8601)
  updatedAt: string;         // 最后修改时间
  recordedAt?: string;       // 梦境发生日期 (默认为创建日期)
}

// 情绪枚举
type EmotionType = 'joy' | 'calm' | 'sadness' | 'fear' | 'wonder' | 'nostalgia';

// 情绪元数据映射
const EMOTION_META: Record<EmotionType, EmotionMeta> = {
  joy:       { label: '喜悦', icon: '☀️', color: '#F5A623', bg: 'linear-gradient(135deg, #FFF8E1, #FFE0B2)' },
  calm:      { label: '平静', icon: '🌙', color: '#7EC8E3', bg: 'linear-gradient(135deg, #E3F2FD, #BBDEFB)' },
  sadness:   { label: '悲伤', icon: '🌧️', color: '#6C63FF', bg: 'linear-gradient(135deg, #EDE7F6, #D1C4E9)' },
  fear:      { label: '恐惧', icon: '🌫️', color: '#4A4A4A', bg: 'linear-gradient(135deg, #ECEFF1, #CFD8DC)' },
  wonder:    { label: '奇妙', icon: '✨', color: '#E040FB', bg: 'linear-gradient(135deg, #F3E5F5, #E1BEE7)' },
  nostalgia: { label: '怀念', icon: '🌅', color: '#FF8A65', bg: 'linear-gradient(135deg, #FBE9E7, #FFCCBC)' },
};
```

### 5.3 数据存储策略

| 层级 | 技术 | 用途 |
|------|------|------|
| **运行时状态** | React State / Vue Reactivity | 页面交互状态、表单数据 |
| **客户端持久化** | localStorage | 梦境数据、用户标识、草稿 |
| **会话隔离** | localStorage Key 前缀 + userId | `dreampatrol_{userId}_dreams` |

> 注：因时间限制（8 小时冲刺），优先使用 localStorage 方案。如需升级，可后续迁移至 IndexedDB 以支持更大数据量和结构化查询。

## 6. 交互设计规范

### 6.1 设计语言

- 标记点 → 同一日期可有多色圆点（多梦重叠）；
- 无梦日期 → 无标记，视觉上保持干净。

#### 6.2.3 空状态 & 边界处理

| 场景 | 处理方式 |
|------|----------|
| 无梦境记录 | 展示引导插画 + "还没有梦被留下" + 新建按钮 |
| 空输入提交 | 阻止提交，Toast 提示"梦还空着呢，写点什么吧" |
| 超长输入 (>5000字) | 接受但温和提示"这个梦很长呢，会被完整保存" |
| 语音不可用 | 隐藏语音按钮，不展示不可用状态 |
| 删除梦境 | 二次确认弹窗"删除后，这个梦就真的消失了" |
| 网络异常 | 完全离线可用，localStorage 不依赖网络 |

#### 6.2.4 动画 & 微交互

| 场景 | 动画 | 意图 |
|------|------|------|
| 提交梦境 | 星尘粒子上升消散 | 象征"梦被安放到星空" |
| 进入详情 | 卡片放大 + 背景渐变过渡 | 营造"进入梦境"的空间感 |
| 日历标记 | 日期标记点微呼吸动画 | 吸引注意，暗示"这里有梦" |
| 情绪选择 | 图标微放大 + 色彩扩散 | 强化情绪被"选中确认"的仪式感 |
| 页面切换 | 柔和淡入淡出 (300ms) | 不打断用户的沉浸状态 |

### 7.3 关键技术实现要点

#### 7.3.1 语音录入

```typescript
// 核心思路：封装 Web Speech API
const useSpeechRecognition = () => {
  const [transcript, setTranscript] = useState('');
  const [isListening, setIsListening] = useState(false);

  const startListening = () => {
    const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
    if (!SpeechRecognition) return; // 不支持则静默降级

    const recognition = new SpeechRecognition();
    recognition.lang = 'zh-CN';
    recognition.interimResults = true;
    recognition.continuous = true;

    recognition.onresult = (event) => {
      const result = Array.from(event.results)
        .map(r => r[0].transcript)
        .join('');
      setTranscript(result);
    };

    recognition.start();
    setIsListening(true);
  };

  return { transcript, isListening, startListening, stopListening };
};
```

#### 7.3.3 数据持久化与隔离

```typescript
// 基于 userId 的数据隔离
const STORAGE_PREFIX = 'dreampatrol';

const getUserId = (): string => {
  let userId = localStorage.getItem(`${STORAGE_PREFIX}_userId`);
  if (!userId) {
    userId = crypto.randomUUID();
    localStorage.setItem(`${STORAGE_PREFIX}_userId`, userId);
  }
  return userId;
};

const saveDreams = (dreams: Dream[]) => {
  const userId = getUserId();
  localStorage.setItem(
    `${STORAGE_PREFIX}_${userId}_dreams`,
    JSON.stringify(dreams)
  );
};

const loadDreams = (): Dream[] => {
  const userId = getUserId();
  const raw = localStorage.getItem(`${STORAGE_PREFIX}_${userId}_dreams`);
  return raw ? JSON.parse(raw) : [];
};
```

#### 7.3.4 草稿自动保存

```typescript
// 使用 useRef + setInterval 实现防抖自动保存
useEffect(() => {
  const timer = setInterval(() => {
    if (draftContent.trim()) {
      localStorage.setItem(`${STORAGE_PREFIX}_draft`, draftContent);
    }
  }, 30000); // 30 秒自动保存
  return () => clearInterval(timer);
}, [draftContent]);
```

### 7.4 性能优化策略

| 策略 | 说明 |
