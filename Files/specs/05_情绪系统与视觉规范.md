## 三、字体层级（执行规范）

| 层级 | CSS实现 | 使用场景 |
|------|---------|----------|
| **H1** | `font-size: var(--font-size-xl); font-weight: var(--font-weight-bold);` | 页面标题，如"巡梦" |
| **H2** | `font-size: var(--font-size-lg); font-weight: var(--font-weight-semibold);` | 区域标题，如"记录你的梦" |
| **H3** | `font-size: var(--font-size-md); font-weight: var(--font-weight-medium);` | 卡片标题 |
| **Body** | `font-size: var(--font-size-md); font-weight: var(--font-weight-regular); line-height: var(--line-height-relaxed);` | 梦境正文 |
| **Caption** | `font-size: var(--font-size-sm); color: var(--color-text-secondary);` | 日期、辅助信息 |
| **Small** | `font-size: var(--font-size-xs); color: var(--color-text-secondary);` | 字数统计、占位提示 |

## 五、动画规范

### 5.1 关键帧定义

```css
/* 页面入场 */
@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(8px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* Toast入场 */
@keyframes slideUp {
  from {
    opacity: 0;
    transform: translateY(16px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* 语音录制波形 */
@keyframes pulse {
  0%, 100% { transform: scale(1); opacity: 0.6; }
  50% { transform: scale(1.3); opacity: 1; }
}

/* 日历标记点呼吸 */
@keyframes breathe {
  0%, 100% { transform: scale(1); opacity: 0.8; }
  50% { transform: scale(1.4); opacity: 1; }
}

/* 情绪色渐变流动（详情页背景） */
@keyframes gradientShift {
  0% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}
```

### 5.2 动画应用规则

| 元素 | 动画 | 时长 | easing |
|------|------|------|--------|
| 页面容器 | `fadeInUp` | 300ms | ease |
| Toast | `slideUp` | 300ms | ease-out |
| 日历标记点 | `breathe` | 2s | ease-in-out (infinite) |
| 语音录制指示器 | `pulse` | 1.5s | ease-in-out (infinite) |
| 详情页背景 | `gradientShift` | 10s | ease (infinite) |
| 卡片hover | `transform: translateY(-2px)` | 150ms | ease |
| 情绪选项hover | `transform: scale(1.05)` | 200ms | ease |
| 弹窗入场 | `fadeInUp` | 200ms | ease-out |

### 5.3 动画控制

```css
/* 全局动画开关（演示时性能优化用） */
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 六、情绪主题系统实现

### 6.1 主题切换原理

```
1. 用户在NewDreamPage选择情绪 或 进入DreamDetailPage
2. useEmotionTheme(emotion) Hook被调用
3. Hook修改 document.documentElement 上的CSS变量：
   --emotion-color → EMOTION_META[emotion].color
   --emotion-bg    → EMOTION_META[emotion].bgGradient
4. 所有使用了 var(--emotion-color) 和 var(--emotion-bg) 的元素自动响应变化
5. 组件卸载时恢复默认值
```

### 6.2 受情绪主题影响的元素

| 元素/页面 | CSS变量使用 |
|-----------|------------|
| DreamDetailPage 背景 | `background: var(--emotion-bg)` |
| DreamCard 左侧色条 | `background-color: var(--emotion-color)` |
| 日历标记点 | `background-color: var(--emotion-color)` |
| EmotionPicker 选中态边框 | `border-color: var(--emotion-color)` |
| 情绪标签Badge | `background-color: var(--emotion-color)` |

### 6.3 默认主题（无情绪时）

```css
/* 首页/列表/日历等非详情页面使用默认主题 */
--emotion-color: var(--color-primary);
--emotion-bg: var(--color-bg);
```
