## 一、产品定义

### 1.1 一句话定位

> 「巡梦」是一个专为"做梦"而生的梦境记录Web应用——用户通过文字或语音留下每一个梦，标记情绪，在日历中回溯梦境历程，在回看时感受情绪氛围的沉浸承接。

### 1.2 核心差异点

| 对比维度 | 普通笔记工具 | 巡梦 |
|----------|-------------|------|
| 记录方式 | 纯文本 | 文本 + 语音 |
| 回顾视角 | 时间线列表 | 日历星图 + 卡片列表 |
| 情绪表达 | 无 | 6种情绪标记 + 氛围背景色承接 |
| 核心体验 | 功能式 | 沉浸式（记录→标记→回看→情绪承接闭环） |

### 1.3 目标用户

- 频繁做梦、希望记录和回顾梦境内容的人
- 梦境伴随强烈情绪、需要一个空间安放这些情绪的人
- 对探索自己潜意识有兴趣的人

### 1.4 使用场景

| 场景 | 用户状态 | 核心操作 | 对应页面 |
|------|----------|----------|----------|
| S1-晨起记录 | 朦胧、半醒 | 语音或文字快速记录梦境 | NewDreamPage |
| S2-午后补全 | 清醒、专注 | 编辑完善梦境细节 | EditDreamPage |
| S3-周末回溯 | 放松、好奇 | 日历查看、浏览历史梦境 | CalendarPage / HomePage |
| S4-沉浸重温 | 感性、沉浸 | 查看详情、感受情绪氛围 | DreamDetailPage |

## 三、路由表

| 路径 | 页面组件 | 说明 | 懒加载 |
|------|----------|------|--------|
| `/` | `HomePage` | 首页，梦境卡片列表 | 否（首页） |
| `/new` | `NewDreamPage` | 新建梦境 | 是 |
| `/dream/:id` | `DreamDetailPage` | 梦境详情 | 是 |
| `/dream/:id/edit` | `EditDreamPage` | 编辑梦境 | 是 |
| `/calendar` | `CalendarPage` | 日历视图 | 是 |

路由实现要求（React Router v6）：

```typescript
// App.tsx 路由配置示意
<Routes>
  <Route path="/" element={<Layout />}>
    <Route index element={<HomePage />} />
    <Route path="new" element={<Suspense fallback={<Loading />}><NewDreamPage /></Suspense>} />
    <Route path="dream/:id" element={<Suspense fallback={<Loading />}><DreamDetailPage /></Suspense>} />
    <Route path="dream/:id/edit" element={<Suspense fallback={<Loading />}><EditDreamPage /></Suspense>} />
    <Route path="calendar" element={<Suspense fallback={<Loading />}><CalendarPage /></Suspense>} />
  </Route>
</Routes>
```

### 4.2 数据流

```
用户操作 → Page组件 → useDreams Hook → storage.ts → localStorage
                ↕ (dispatch)
           DreamContext (全局状态同步)

特殊流：
用户语音 → useSpeech Hook → Web Speech API → transcript → Textarea
```

### 4.3 无外部依赖说明

本方案**不依赖任何后端服务、第三方API、外部数据库**。所有功能通过浏览器原生能力实现：

- **数据持久化**：localStorage（浏览器内置）
- **语音转文字**：Web Speech API（浏览器内置，Chrome/Edge/Safari支持）
- **情绪分析**：前端关键词匹配规则引擎（见05号文档）
- **部署方式**：`npx vite build` 生成静态文件，双击index.html即可运行

## 五、技术约束与要求

| 约束项 | 要求 |
|--------|------|
| TypeScript | strict模式，禁止`any`（除非有充分理由） |
| 组件 | 函数组件 + Hooks，禁止Class组件 |
| 样式 | CSS Modules + CSS Variables，禁止内联style |
| Props | 所有组件Props必须有interface定义 |
| 导出 | 组件使用`export default`，工具函数使用`export named` |
| 副作用 | useEffect必须清理（return cleanup函数） |
| 键值 | 列表渲染必须使用唯一稳定的key（dream.id，禁止index） |
