## 二、技术栈决策（AI编码前必读）

### 2.1 最终选型

| 层次 | 技术 | 版本要求 | 选型理由 |
|------|------|----------|----------|
| **框架** | React | 18.x | 生态最成熟，AI生成代码质量最高 |
| **语言** | TypeScript | 5.x | 类型安全，减少运行时错误 |
| **构建** | Vite | 5.x | 秒级冷启动，极速HMR |
| **路由** | React Router | 6.x | 声明式路由，支持懒加载 |
| **样式** | CSS Modules | 内置于Vite | 零运行时，天然作用域隔离 |
| **状态** | React Context + useReducer | React内置 | 无需额外依赖 |
| **语音** | Web Speech API | 浏览器原生 | 零依赖，满足第二录入方式 |
| **持久化** | localStorage | 浏览器原生 | 满足赛题全部持久化要求 |
| **动画** | CSS Animations + Transition | 浏览器原生 | 性能最优 |
| **部署** | 静态HTML (vite build) | — | 双击即用，演示零风险 |

### 2.2 禁止使用的技术

| 技术 | 原因 |
|------|------|
| Flutter | Web部署复杂，8h内不可行 |
| Langchain/Langgraph/Langsmith | 重型AI框架，远超赛题需求 |
| MongoDB/Redis | 8h冲刺不需要后端数据库 |
| Node.js/Express | 纯前端方案即可满足所有需求 |
| Tailwind CSS | 增加构建复杂度，CSS Modules更直接 |
| Framer Motion | 额外依赖，CSS动画已足够 |

### 2.3 依赖清单

```json
{
  "dependencies": {
    "react": "^18.3.0",
    "react-dom": "^18.3.0",
    "react-router-dom": "^6.23.0"
  },
  "devDependencies": {

```

**总计：仅3个运行时依赖 + 4个开发依赖。** 这是刻意为之——最少依赖意味着最少问题。

## 三、AI编程开发顺序（关键）

### 3.1 必须按以下阶段顺序开发

```
阶段一：骨架（预计 2h）
  └─ 1. Vite项目初始化 → 路由搭建 → Layout组件 → 全局CSS变量

阶段二：数据层（预计 30min）
  └─ 2. 阅读 02_核心数据模型与存储设计.md → 实现 types/dream.ts
  └─ 3. 阅读 02_核心数据模型与存储设计.md → 实现 services/storage.ts

阶段三：核心页面（预计 3h）
  └─ 4. 阅读 03_页面组件规格书.md → 实现 HomePage（梦境列表）
  └─ 5. 阅读 03_页面组件规格书.md → 实现 NewDreamPage（新建梦境+情绪选择器+语音）
  └─ 6. 阅读 03_页面组件规格书.md → 实现 DreamDetailPage（详情页+氛围背景）
  └─ 7. 阅读 03_页面组件规格书.md → 实现 CalendarPage（日历视图）

阶段四：体验打磨（预计 1.5h）
  └─ 8. 阅读 05_情绪系统与视觉规范.md → 实现情绪主题系统（CSS变量切换）
  └─ 9. 阅读 04_交互流程与状态管理.md → 实现全局状态管理（Context+useReducer）
  └─ 10. 阅读 04_交互流程与状态管理.md → 实现边界处理（空状态/错误/确认弹窗）

阶段五：收尾（预计 1h）
  └─ 11. 阅读 03_页面组件规格书.md → 实现 EditDreamPage
  └─ 12. 编写 README.md
  └─ 13. 构建测试、演示视频录制
```

### 3.2 P0/P1/P2 优先级定义

| 优先级 | 含义 | 涵盖范围 |
|--------|------|----------|
| **P0** | 不做就扣分 | 文本+语音录入、情绪标记、列表、详情、日历、localStorage持久化、基础氛围背景色 |
| **P1** | 做了就加分 | 情绪主题系统（全页面CSS变量联动）、动画微交互、空状态/边界处理、编辑功能 |
| **P2** | 时间宽裕才做 | 搜索筛选、情绪统计图表、草稿自动保存、响应式适配、粒子动效 |

## 四、AI编码使用指南

### 4.1 如何让AI精准生成代码

将以下文档**按顺序**作为AI上下文输入：

1. 先输入 `01_产品概述与系统架构.md` — 让AI理解产品全貌
2. 再输入 `02_核心数据模型与存储设计.md` — 所有类型定义和数据结构
3. 然后根据当前开发阶段，选择输入对应文档：
   - 写组件 → `03_页面组件规格书.md`
   - 写交互 → `04_交互流程与状态管理.md`
   - 写样式 → `05_情绪系统与视觉规范.md`

### 4.2 Prompt模板

```
你是一个前端开发专家，请基于以下产品规格文档，实现[具体功能]。
技术栈：React 18 + TypeScript + Vite + CSS Modules + React Router v6。
请严格遵循文档中定义的数据类型、组件Props接口和状态管理Schema。
代码要求：TypeScript严格模式、所有Props有明确类型、CSS使用CSS Variables。
参考文档：[粘贴对应文档内容]
```

### 4.3 文件命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 页面组件 | `PascalCase + Page后缀` | `HomePage.tsx` |
| 通用组件 | `PascalCase` | `DreamCard.tsx` |
| 自定义Hook | `camelCase + use前缀` | `useDreams.ts` |
| 服务层 | `camelCase` | `storage.ts` |
| 类型文件 | `camelCase` | `dream.ts` |
| 样式文件 | `同组件名.module.css` | `DreamCard.module.css` |
