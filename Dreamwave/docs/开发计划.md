## 三、数据库设计

### 3.1 ER关系图

```
┌──────────────┐       ┌──────────────────┐       ┌──────────────┐
│    users     │       │     dreams       │       │    tags      │
├──────────────┤       ├──────────────────┤       ├──────────────┤
│ id (PK)      │──1:N──│ id (PK)          │──N:M──│ id (PK)      │
│ username     │       │ user_id (FK)     │       │ user_id (FK) │
│ password_hash│       │ title            │       │ name         │
│ created_at   │       │ content          │       │ color        │
│ updated_at   │       │ emotion          │       │ created_at   │
│ is_active    │       │ narrative        │       └──────────────┘
└──────────────┘       │ recorded_date    │              │
                       │ is_favorite      │              │
                       │ created_at       │       ┌──────────────────┐
                       │ updated_at       │       │  dream_tags      │
                       └──────────────────┘       ├──────────────────┤
                                                   │ dream_id (FK)    │
                                                   │ tag_id (FK)      │
                                                   └──────────────────┘
```

### 3.2 表结构定义

#### users 表

```sql
CREATE TABLE users (
  id          TEXT PRIMARY KEY,           -- UUID
  username    TEXT NOT NULL UNIQUE,       -- 用户名
  password_hash TEXT NOT NULL,            -- bcrypt哈希
  role        TEXT NOT NULL DEFAULT 'user', -- user/admin
  created_at  TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at  TEXT NOT NULL DEFAULT (datetime('now')),
  is_active   INTEGER NOT NULL DEFAULT 1 -- 1=活跃 0=禁用
);
```

#### dreams 表

```sql
CREATE TABLE dreams (
  id            TEXT PRIMARY KEY,           -- UUID
  user_id       TEXT NOT NULL,              -- 外键→users.id
  title         TEXT NOT NULL,              -- 自动取content前30字符
  content       TEXT NOT NULL,              -- 梦境正文
  emotion       TEXT NOT NULL,              -- EmotionType枚举值
  narrative     TEXT,                       -- 叙事生成结果（可选）
  recorded_date TEXT NOT NULL,              -- YYYY-MM-DD
  is_favorite   INTEGER NOT NULL DEFAULT 0, -- 0=普通 1=收藏
  created_at    TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at    TEXT NOT NULL DEFAULT (datetime('now')),
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE INDEX idx_dreams_user_id ON dreams(user_id);
CREATE INDEX idx_dreams_recorded_date ON dreams(recorded_date);
CREATE INDEX idx_dreams_emotion ON dreams(emotion);
CREATE INDEX idx_dreams_is_favorite ON dreams(is_favorite);
```

#### tags 表

```sql
CREATE TABLE tags (
  id         TEXT PRIMARY KEY,            -- UUID
  user_id    TEXT NOT NULL,               -- 外键→users.id
  name       TEXT NOT NULL,               -- 标签名
  color      TEXT NOT NULL DEFAULT '#7EB8DA', -- 标签颜色
  created_at TEXT NOT NULL DEFAULT (datetime('now')),
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
  UNIQUE(user_id, name)
);

CREATE INDEX idx_tags_user_id ON tags(user_id);
```

#### dream_tags 关联表

```sql
CREATE TABLE dream_tags (
  dream_id TEXT NOT NULL,                 -- 外键→dreams.id
  tag_id   TEXT NOT NULL,                 -- 外键→tags.id
  PRIMARY KEY (dream_id, tag_id),
  FOREIGN KEY (dream_id) REFERENCES dreams(id) ON DELETE CASCADE,
  FOREIGN KEY (tag_id) REFERENCES tags(id) ON DELETE CASCADE
);
```

## 四、API接口规范

### 4.1 基础信息

| 项目 | 值 |
|------|-----|
| Base URL | `http://localhost:3100/api` |
| 数据格式 | JSON |
| 认证方式 | Bearer Token (JWT) |
| 字符编码 | UTF-8 |

### 4.2 认证接口

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | `/auth/register` | 用户注册 | 无 |
| POST | `/auth/login` | 用户登录 | 无 |
| GET | `/auth/me` | 获取当前用户信息 | 需要 |
| POST | `/auth/logout` | 登出（Token黑名单） | 需要 |
| POST | `/auth/refresh` | 刷新Token | 需要 |
| PUT | `/auth/password` | 修改密码 | 需要 |

### 4.3 梦境接口

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | `/dreams` | 获取当前用户所有梦境（支持筛选） | 需要 |
| POST | `/dreams` | 创建梦境 | 需要 |
| GET | `/dreams/dates/list` | 获取有记录的日期列表 | 需要 |
| GET | `/dreams/date/:date` | 按日期查询 | 需要 |
| GET | `/dreams/search` | 全文搜索 | 需要 |
| GET | `/dreams/:id` | 获取单个梦境 | 需要 |
| PUT | `/dreams/:id` | 更新梦境 | 需要 |
| DELETE | `/dreams/:id` | 删除梦境 | 需要 |
| POST | `/dreams/:id/narrative` | 生成叙事 | 需要 |
| PUT | `/dreams/:id/favorite` | 收藏/取消收藏 | 需要 |
| GET | `/dreams/stats` | 个人梦境统计 | 需要 |
| GET | `/dreams/export` | 导出梦境数据 | 需要 |

#### GET /dreams

```typescript
// Query: ?emotion=joy&tag=tagId&page=1&limit=20&keyword=xxx&favorite=true
// Response 200
{
  dreams: Dream[];
  total: number;
  page: number;
  limit: number;
}
```

#### POST /dreams

```typescript
// Request
{ content: string; emotion: EmotionType; recordedDate?: string; tagIds?: string[] }

// Response 201
{ dream: Dream }
```

### 4.4 标签接口

| 方法 | 路径 | 说明 | 认证 |

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | `/admin/stats` | 数据概览统计 | 管理员 |
| GET | `/admin/stats/trends` | 趋势数据（近N天） | 管理员 |
| GET | `/admin/dreams` | 所有梦境列表 | 管理员 |

```typescript
{ error: string; code?: string; details?: any }
```

| HTTP状态码 | 含义 |
|-----------|------|
| 400 | 请求参数错误 |
| 401 | 未认证/Token失效 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 429 | 请求过于频繁 |
