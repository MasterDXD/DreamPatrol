# 资源清单与版权说明

> 本文档对应「巡梦」（Dream Patrol）Web 应用，记录 `g:\DreamPatrol\Files\assets\` 目录下所有静态资源的来源、用途、规格及版权信息，供产品设计、开发与参赛评审查阅。

## 一、目录结构与命名规范

```
g:\DreamPatrol\Files\assets\
├── audio\    # 白噪音 / 氛围音
├── icons\    # 表情图标 / Logo / Favicon
└── images\   # 情绪主题背景图
```

**统一命名格式：**

```
dream-patrol_{type}_{name}.{ext}
```

- `type`：资源类型（`white-noise` / `bg` / `icon` / `favicon` / `logo`）
- `name`：语义名称（如 `rain`、`joy` 情绪名等）
- `ext`：扩展名（mp3 / jpg / png）
